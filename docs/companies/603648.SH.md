# 畅联股份 · 公司生意笔记

畅联股份（上海畅联国际物流）专注于为国际跨国企业提供精益供应链管理服务：为高科技电子、医疗器械和试剂、机械装备部件、进口食品和服饰等高端消费品、精益制造领域的客户，提供供应链综合管理方案设计与实施，以及配套的口岸通关、仓储管理、货物配送一体化综合物流服务，客户包括苹果、碧迪、泡泡玛特、卡尔史托斯、波科医疗、希森美康、捷豹路虎等。2025年营业收入15.37亿元，同比增长1.17%，其中供应链物流占99.43%；主营业务毛利率19.88%。归母净利润1.23亿元，同比下降5.89%。

资料日期：2026-04-27。

## 公司卖什么，解决什么问题？

畅联股份为国际跨国企业解决供应链各环节的物流管理问题。在供应链上游，为客户提供原材料与零部件采购服务、原材料入场物流、原材料库存管理；在下游提供生产线后端物流加工、产成品销售物流、零部件售后物流，并配套口岸通关、仓储管理、货物配送，帮助客户协调优化供应链流程、提高效率并降低运营成本。服务领域集中于高科技电子、医疗器械和试剂、机械装备部件、进口食品和服饰等高端消费品、精益制造；客户多为知名跨国公司（苹果、碧迪、泡泡玛特、卡尔史托斯、波科医疗、三菱、希森美康、捷豹路虎等）。截至2025年末已设立39家分子公司，覆盖国内主要枢纽城市及香港，并在越南设有全资子公司。

## 主要靠什么获得收入？

2025年营业收入15.37亿元，同比增长1.17%。分产品：供应链物流15.28亿元，占99.43%，毛利率19.92%（同比+1.80%）；供应链贸易（贸易采购执行）841.74万元，占0.55%，同比下降52.84%。分地区看，内地收入15.03亿元，香港收入3,191.39万元（+190.29%，毛利率65.97%），越南165.98万元。

盈利：主营业务毛利率19.88%；归母净利润1.23亿元（-5.89%），扣非归母净利润1.14亿元（-11.98%）。成本特征：基础物流外包成本7.21亿元、占营业成本58.52%，人工成本占17.71%——大量运输仓储作业通过外包完成，公司核心在供应链管理方案与信息化能力。

公司服务属性强、资产模式轻：基础物流外包成本占营业成本58.52%，公司以供应链管理方案与信息化系统为核心能力。

供应链物流与供应链贸易是两类口径：物流服务收取服务费，贸易采购执行为购销业务（本期已大幅收缩至841.74万元）。

2025年归母净利润1.23亿元、扣非归母净利润1.14亿元，分别下降5.89%和11.98%；营业收入微增1.17%但毛利率下降1.81个百分点。
