# 汉桑科技 · 公司生意笔记

[← 公司目录](README.md) · `301491.SZ`

汉桑把音频技术、产品设计和制造结合起来，既做家庭高保真音响与商用音频设备，也与品牌客户开发儿童、游戏、运动等场景的智能音频硬件。

## 生意概览

资料日期：2026-04-23。

### 公司卖什么，解决什么问题？

它提供高性能音频产品、创新音频产品及相关模组配件。高性能音频覆盖家庭音响、影院和商用场景；创新音频包括具有音频与交互功能的儿童、游戏、运动及家居智能硬件。

### 主要靠什么获得收入？

2025年，创新音频产品占营业收入67.89%，是最大的收入类别；高性能音频产品占27.93%，其他产品及服务占4.18%。创新音频涵盖多种智能硬件，这个占比不能全部归给某一种儿童设备或某个AI产品。
