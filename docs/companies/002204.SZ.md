# 大连重工 · 公司生意笔记

看大连重工的生意，物料搬运设备和新能源设备各占约三成，冶金设备、核心零部件和工程总包构成其余部分。

资料日期：2026-04-17。

## 公司卖什么，解决什么问题？

大连重工主要从事物料搬运设备、冶金设备、新能源设备、传动与控制系统、船用设备等领域大型成套设备及核心零部件的开发和销售。物料搬运设备包括堆取料机、翻车机等装卸机械，冶金起重机等起重机械，卸船机、岸桥等港口机械；新能源设备包括风电齿轮箱、轮毂、塔筒等风电零部件和核电站专用起重机；冶金设备包括炼焦机械、连铸机械、轧钢机械；核心零部件包括齿轮传动系统、电气控制系统和船用曲轴；并具备重大技术装备工程总承包能力。

## 主要靠什么获得收入？

2025年营业收入155.17亿元，同比增长8.66%。物料搬运设备占31.13%，新能源设备占31.03%，两大板块合计约六成二；冶金设备占16.51%，核心零部件占13.11%，工程总包占6.37%。境外销售占15.74%。

## 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 电厂、码头、钢厂需要搬运散料与重物 | 制造堆取料机、起重机、卸船机等大型设备 | 取得物料搬运设备销售收入 |
| 风电与核电建设需要大型部件与专用设备 | 制造风电零部件和核电站专用起重机 | 取得新能源设备销售收入 |
| 冶金企业需要冶炼与轧制装备 | 制造炼焦、连铸、轧钢设备并可工程总包 | 取得冶金设备与工程收入 |
| 船舶与工业装备需要传动部件 | 制造齿轮传动、电控系统和船用曲轴 | 取得核心零部件销售收入 |

物料搬运与新能源两大板块合计约六成二；新能源设备收入占比已从27.76%升至31.03%，但毛利率仅约10%，是各板块中最低。
