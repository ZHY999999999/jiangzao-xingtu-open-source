# 南玻A · 公司生意笔记

[← 公司目录](README.md) · `000012.SZ`

南玻的大部分收入来自玻璃产业。不同玻璃分别进入建筑、太阳能组件和电子设备，生产路线和用途并不相同。

## 生意概览

资料日期：2026-04-28。

### 公司卖什么，解决什么问题？

浮法玻璃供下游继续加工；工程玻璃用于节能门窗和幕墙；光伏玻璃用于封装太阳能组件。电子玻璃、导电薄膜和盖板用于消费电子、车载显示及触控设备；硅料、硅片和组件属于另一条太阳能制造业务。

### 怎样把产品或服务交付出去？

以工程玻璃为例，公司围绕建筑项目需求做研发设计、技术咨询、生产和销售，把原片加工成节能玻璃后交付。光伏玻璃和电子触控产品各有生产路线。国内产品按约定运到交货地点或由买方自提，买方确认接收后形成收入，货款可能稍后才收齐。

### 主要成本与风险是什么？

制造成本包括材料、人工和设备使用中逐年计入的折旧，原材料与能源价格会影响盈利。窑炉和工厂还需要投入：2025年工程项目建设现金支出约10.23亿元，另有研发费用约5.19亿元。投产或在建资产若预计收不回原有价值，还要确认减值损失，压低当期利润。

### 在产业链里处于什么位置？

南玻主要处在材料和器件制造这一环，服务建筑、光伏和电子产业下游。年报描述的压力也不同：浮法玻璃受房地产需求走弱影响，光伏玻璃面临供过于求和价格压力，电子业务则在拓展不同应用。不能只凭“都叫玻璃”判断所有产品的生意。

### 经营发生了什么变化？

2025年，归属于上市公司股东的净利润约1.26亿元，但扣除非经常性损益后亏约1.07亿元，盈利有非经常性项目的支撑。2026年上半年转亏约4.21亿元；主力玻璃业务收入减少、成本却略增，每一元销售留下的毛利被明显挤压。同期经营现金流仍为正但同比减少，现金为正不等于盈利改善；半年报未经审计。
