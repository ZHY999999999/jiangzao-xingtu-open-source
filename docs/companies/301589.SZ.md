# 诺瓦星云 · 公司生意笔记

[← 公司目录](README.md) · `301589.SZ`

诺瓦星云服务显示屏厂商和行业客户，解决视频怎样传到屏幕、怎样拼接切换，以及怎样远程发布内容和管理屏幕的问题。产品既有硬件，也有配套软件与云服务。

## 生意概览

资料日期：2026-04-25。

### 公司卖什么，解决什么问题？

它提供LED显示控制系统、视频处理系统，以及基于云的信息发布与管理系统。发送卡和接收卡控制LED显示，处理器与拼接切换设备处理视频，联网播放器及云平台支持内容发布、监控和维护。

### 主要靠什么获得收入？

2025年，视频处理系统占营业收入42.75%，LED显示控制系统占40.67%，基于云的信息发布与管理系统占7.35%，配件及其他占7.62%，其他业务占1.61%。云相关分类同时包含硬件播放器和软件产品，不能把7.35%全部视为云订阅费。
