# 贵州燃气 · 公司生意笔记

贵州燃气主要从事城市燃气运营，业务覆盖贵州省主要城市、核心经济区和主要工业园区，在贵州省天然气市场占主导地位。2025年公司实现天然气销售量18.85亿立方米，完成营业收入66.41亿元，归属于母公司股东的净利润0.47亿元。

资料日期：2026-04-23。

## 公司卖什么，解决什么问题？

公司主要从事城市燃气运营：从上游供应商购入管道天然气、液化天然气、页岩气及生物质气等气源，通过天然气支线管道、门站、储配站、各级输配管网等设施，输送和分配给城市居民、商业、工业、采暖、加气站、综合用能等用户，并承担天然气支线管道、城市燃气输配系统、液化天然气接收储备供应站、加气站等设施的建设、运营、服务管理以及相应的工程设计、施工、维修，同时为客户提供以天然气为主、多种清洁能源为辅的综合能源供应服务。公司在贵州省内已建成6条天然气支线管道，在省内38个特定区域及1个省外特定区域取得管道燃气特许经营权。

## 主要靠什么获得收入？

2025年营业收入66.41亿元。主营业务分产品：天然气销售和安装65.08亿元（约占营业收入98.0%）、综合能源供应服务0.17亿元（约0.3%）。也就是说，收入几乎全部来自天然气销售和安装。分地区看，省内63.21亿元、省外2.04亿元，生意基本在贵州省内。
