# *ST美丽 · 公司生意笔记

### 怎样把产品或服务交付出去？

公司承接项目后，要组织施工人员和资源，安排施工过程，检查进场材料及关键工序，并完成相关验收。部分工程按约定分阶段计量、结算，公司再推进工程款回收。工程已做了多少、已确认多少收入、客户最终付了多少钱可能不同：业主确认和结算审核需要时间，不能把确认收入直接当成收到现金。

### 经营发生了什么变化？

按公司报表列示，2025年归母净利润亏损约0.35亿元，扣除非经常性损益后亏损更多（约1.03亿元）；2026年上半年归母亏损约0.17亿元，较上年同期收窄。这两个期间的经营现金流净额也都为负，减亏不等于已经恢复盈利或资金充裕。

更重要的是财务信息限制：公司自查发现股东经第三方账户代部分客户付款，审计机构无法取得充分证据判断相关交易的商业实质及报表影响，因此对2025年度财务报表无法表示意见。半年报称相关专项审计仍在进行，半年度财务报表未经审计。无法表示意见并不等于所有数字已被证伪，但也不能把这些数字当成审计确认的经营结果。

截至2026年半年报，公司还披露大额债务逾期、持续经营能力存在重大不确定性，庭外重组能否进入预重整、正式重整及最终成功均不确定。公司继续按持续经营基础编报，不代表这些风险已消除。半年报同时记载股票于2026年4月30日被实施退市风险警示和其他风险警示；这不等于已经退市，也不是对后来状态的推断。
