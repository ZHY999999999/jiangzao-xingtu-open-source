# 曙光数创 · 公司生意笔记

[← 公司目录](README.md) · `920808.BJ`

曙光数创解决的是服务器密集运行时的散热问题，主要通过销售液冷基础设施产品和提供相关服务取得收入。

## 生意概览

资料日期：2026-04-14。

### 公司卖什么，解决什么问题？

公司主要提供浸没液冷、冷板液冷和模块化数据中心产品，以及系统集成、技术服务。浸没液冷把服务器或组件浸入冷媒带走热量；冷板液冷则通过贴近发热器件的冷板，把热量传给循环液体。客户来自科研、政府、金融、互联网、运营商等领域。

### 主要靠什么获得收入？

2025年营业收入约8.82亿元。按全部营业收入计算，浸没液冷产品约占51.90%，冷板液冷产品约占33.85%，两者合计约占85.75%；此外还有模块化产品、配套产品及服务收入。收入主体是液冷产品。
