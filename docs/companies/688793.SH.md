# 倍轻松 · 公司生意笔记

[← 公司目录](README.md) · `688793.SH`

销售便携式按摩器，覆盖肩部、头部、眼部等使用部位。

## 生意概览

资料日期：2026-04-30。

### 公司卖什么，解决什么问题？

公司设计、研发、生产和销售便携按摩器，主要经营自主品牌，通过线上线下渠道销售肩部、头皮及头部、眼部、颈部和腰背部等按摩产品。
