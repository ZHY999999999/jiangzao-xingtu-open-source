# 小崧股份 · 公司生意笔记

[← 公司目录](README.md) · `002723.SZ`

小崧的家电业务服务照明、通风和生活环境需求。读2025年收入时，还要把当年的施工和新增网络影视业务一起看。

## 生意概览

资料日期：2026-04-25。

### 公司卖什么，解决什么问题？

公司研发制造可充电照明灯具、交直流两用风扇、空气净化器等生活电器，通过自有品牌和为其他品牌设计制造两种方式销售。2025年收入中还包括工程施工和网络影视；年底国海建设由全资子公司变为持股49%的参股公司，不能把当年的施工收入直接当成以后仍会持续并入的业务。

### 主要靠什么获得收入？

2025年营业收入10.05亿元：家电业务占68.08%，工程施工占27.19%，影视业务占4.73%。家电里面，风扇和备用照明灯具是较大的产品项，也包括健康电器、电子烟和热泵。网络影视业务从2025年9月开始纳入合并报表，不是完整一年的同口径收入。
