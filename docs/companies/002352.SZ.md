# 顺丰控股 · 公司生意笔记

[← 公司目录](README.md) · [行业入口](../industries/README.md) · `002352.SZ`

<sub>补充研究笔记 · 原稿 2026-10-13 · 本次整理 2026-10-16。按历史披露阅读，未经旧版网站内容验收。</sub>

顺丰控股是亚洲最大、全球第四大综合物流服务提供商，服务超过235万企业客户和超过8亿个人消费者。业务分两大块：速运物流（时效快递、经济快递、快运、冷运及医药、同城即时配送）和供应链及国际（国际快递、国际货运及代理、供应链解决方案）。2025年营业收入3,082.27亿元，同比增长8.37%，其中时效快递1,310.48亿元、占42.52%，是收入的绝对主力。全年归母净利润111.17亿元，同比增长9.31%；但票均收入同比下降11.4%，毛利率13.32%、同比下降0.61个百分点，件量增长（+25.4%）是靠更低单价换来的。

资料日期：2026-03-31。

## 公司卖什么，解决什么问题？

顺丰为企业和个人解决货物与包裹的递送和供应链组织问题。时效快递提供半日达、当日达、次晨达、次日达等高品质门到门服务，是公司的招牌；经济快递做高性价比包裹配送和仓配一体；快运用直营“顺丰快运”加加盟“顺心捷达”双品牌做大件包裹、零担和整车运输；冷运及医药提供生鲜速配、食品冷仓温控配送和-80℃至25℃的医药温控运输；同城即时配送做城市内点到点配送，全城平均1小时送达。供应链及国际板块提供国际快递、跨境电商包裹配送、国际空海铁陆多式联运货代，以及覆盖高科技、汽车、消费品、医药等行业的端到端数智化供应链解决方案。国际业务覆盖95个国家和地区，国际小包覆盖200个国家和地区。

## 主要靠什么获得收入？

2025年营业收入3,082.27亿元，同比增长8.37%。按经营分部：时效快递1,310.48亿元，占42.52%；供应链及国际729.39亿元，占23.66%；快运421.34亿元，占13.67%；经济快递320.53亿元，占10.40%；同城即时配送127.19亿元，占4.13%；冷运及医药106.06亿元，占3.44%；另有各分部“其他”（商品购销等）与未分配部分。按地区：中国内地2,668.18亿元占86.57%，海外315.46亿元占10.23%，港澳台98.62亿元占3.20%。

盈利情况：2025年毛利410.48亿元，毛利率13.32%（同比下降0.61个百分点）；归母净利润111.17亿元，同比增长9.31%，归母净利率3.61%；扣非归母净利润92.64亿元，同比增长1.29%。要注意量的增长与价的下降并存：速运物流业务量166.3亿票，同比增长25.4%，但票均收入13.7元，同比下降11.4%——件量高增长部分来自更低单价的业务结构。

收入结构口径：按经营分部划分含各分部“其他”（主要是端到端供应链服务中涉及的商品购销业务）和“未分配部分”（租赁、技术服务等）；按行业划分97.82%收入来自物流及货运代理。

量增价减：2025年速运物流业务量同比+25.4%，票均收入同比-11.4%（产品结构变化所致）；毛利率13.32%，同比下降0.61个百分点；第四季度毛利率回升至14.28%。

快递是规模生意：归母净利率只有3.61%；成本中人工成本1,297.80亿元（占营业成本48.57%）、运力成本988.996亿元（37.02%）。
