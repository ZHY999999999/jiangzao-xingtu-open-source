# 传化智联 · 公司生意笔记

[← 公司目录](README.md) · [行业入口](../industries/README.md) · `002010.SZ`

<sub>补充研究笔记 · 原稿 2026-10-13 · 本次整理 2026-10-16。按历史披露阅读，未经旧版网站内容验收。</sub>

传化智联有化学和物流两大业务。化学业务以纺织印染助剂为代表的功能化学品和以顺丁橡胶为代表的化工新材料为主，卖给纺织、轮胎、涂料等制造企业；物流业务首创「公路港」平台模式，在全国21个省市自治区布局70个公路港，同时运营线上网络货运平台。2025年营业收入250.84亿元，其中物流占54.92%、化学占45.08%。要注意收入结构：最大的单一产品项是网络货运平台业务（116.64亿元，占46.50%），但毛利率只有2.37%；真正毛利率高的是智能公路港业务（80.86%）和纺织印染助剂（26.27%）。2025年归母净利润5.90亿元，同比增长282.12%，其中包含转让传化支付股权等带来的非经常性投资收益，扣非后归母净利润4.08亿元。

资料日期：2026-04-21。

## 公司卖什么，解决什么问题？

传化智联卖两类东西。

一类是化学品：面向纺织服装企业卖纺织印染助剂（覆盖纤维前处理、染色印花到后整理全流程的千余种方案）和纤维化学品；面向轮胎企业卖顺丁橡胶，其中稀土顺丁橡胶市场占有率国内超70%，公司拥有全球规模最大的稀土顺丁橡胶单体生产基地；还卖粉末涂料用聚酯树脂、高性能有机颜料等。

另一类是物流服务：对中小物流企业和货车司机，提供公路港园区的场地、仓储与配套服务（全国70个公路港，累计入驻企业8,964家）；对货主企业，通过网络货运平台组织运力完成整车运输，并为新能源、化工、快消等行业的头部企业提供端到端供应链物流解决方案。

## 主要靠什么获得收入？

2025年营业收入250.84亿元，同比下降6.05%。分行业看：物流137.76亿元，占54.92%；化学113.08亿元，占45.08%。

分产品看得更清楚：网络货运平台业务116.64亿元，占46.50%，是最大收入来源；纺织印染助剂74.07亿元，占29.53%；顺丁橡胶30.63亿元，占12.21%；智能公路港业务11.88亿元，占4.74%；物流供应链业务5.27亿元，占2.10%；其余涂料及建筑化学品、车后业务、支付保险及其他、房产销售及工程代建合计约4.9%。

收入大不等于赚钱：网络货运平台业务毛利率只有2.37%，物流行业整体毛利率9.89%；而智能公路港业务毛利率80.86%、纺织印染助剂毛利率26.27%、化学行业整体毛利率21.22%。2025年归母净利润5.90亿元（同比+282.12%），但增长部分来自转让传化支付、青岛传化物流基地股权确认的投资收益等非经常项目，扣非后归母净利润4.08亿元。

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 纺织服装与纤维加工企业（买印染助剂、纤维化学品），轮胎企业（买顺丁橡胶），以及家电、汽车、建材等使用粉末涂料树脂和有机颜料的制造企业。 | 研发、生产功能化学品与化工新材料：纺织印染助剂提供覆盖纤维前处理、染色印花至后整理全流程的解决方案；顺丁橡胶建成27万吨级柔联产装置，是全球规模最大的稀土顺丁橡胶单体生产基地，产品出口30余个国家和地区。 | 化学品销售收入：2025年化学行业收入113.08亿元，占营业收入45.08%，毛利率21.22%；其中纺织印染助剂74.07亿元（毛利率26.27%）、顺丁橡胶30.63亿元（毛利率11.10%）。 |
| 有整车运输需求的货主企业，以及平台另一端承接运输的运力方；公路港则服务中小物流企业、货车司机和商贸制造企业。 | 线上运营数字货运网（网络货运平台）组织运输，线下建设运营公路港：在全国21个省市自治区布局公路港项目70个，累计入驻企业8,964家，提供集、分、储、运、配一体化的园区基础设施与配套服务。 | 网络货运平台业务收入116.64亿元（占46.50%），但毛利率仅2.37%，是高流水、薄利润的生意；智能公路港业务收入11.88亿元（占4.74%），毛利率80.86%，规模小但盈利质量高。 |
| 新能源、化工、快消、科技等行业需要一体化物流服务的制造与贸易企业（年报披露的客户案例包括宁德时代、特来电、中石化等头部客户）。 | 以「线上数字货运网+线下智能公路港」双轮驱动，嵌入企业采购、生产、销售全链条：采购端承接原材料集采与入厂物流（VMI），生产端提供线边库管理，销售端覆盖成品分拨、仓配一体及逆向物流。 | 物流供应链业务收入5.27亿元，占营业收入2.10%；年报披露该业务（供应链物流服务）毛利率5.8%。 |

网络货运平台业务贡献了将近一半的收入，但毛利率只有2.37%；看这家公司不能只看收入结构，利润更多来自化学品和公路港。

2025年归母净利润5.90亿元、同比+282.12%，增长原因之一是转让传化支付、青岛传化物流基地股权确认的投资收益（非经常项目）；扣非后归母净利润4.08亿元。收入与利润都要结合非经常性损益看。

分产品中的「支付、保险及其他」收入同比下降82.49%，与公司转让传化支付有限公司股权有关；口径变化影响跨年比较。
