# 四川九洲 · 公司生意笔记

[← 公司目录](README.md) · `000801.SZ`

四川九洲虽然列在家用电器行业中，实际业务包括智能终端、空管装备和微波射频产品，买方主要是运营商及各类机构客户。

## 生意概览

资料日期：2026-04-01。

### 公司卖什么，解决什么问题？

公司为国内外运营商和企业客户提供数字音视频终端、数据通信终端及车载电子产品；为空管相关单位、主机厂所和集成商提供通信、导航、监视等装备与系统；也向科研院所及主机厂所提供微波射频组件、模组。不同业务分别解决网络连接、影音传输、空中交通管理及装备配套需求。

### 主要靠什么获得收入？

2025年营业收入41.12亿元。智能终端占60.00%，空管产品占28.12%，微波射频占9.01%，物业管理占0.94%，其他占1.94%。智能终端贡献最多收入；空管包含多种应用，不能将空管全部收入都称为低空经济收入。

### 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 运营商和企业需要影音、通信与车载终端 | 按需求研发、制造并交付终端设备 | 取得智能终端产品收入 |
| 空管相关机构、主机厂和集成商需要通信导航监视能力 | 交付空管装备、系统方案及相关服务 | 取得空管产品相关收入 |
| 科研院所和主机厂需要装备配套射频器件 | 开发生产组件与功能模组并直接交付 | 取得微波射频产品收入 |

这是三项主要业务路径；物业管理和其他收入另列，空管业务也不等于低空业务。
