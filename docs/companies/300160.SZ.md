# 秀强股份 · 公司生意笔记

[← 公司目录](README.md) · `300160.SZ`

秀强面向企业客户加工玻璃，收入来自玻璃产品交付，而非直接销售冰箱、洗衣机或整套光伏系统。

## 生意概览

资料日期：2026-04-17。

### 公司卖什么，解决什么问题？

公司对原片玻璃进行切片、磨边、钢化、印刷、镀膜等深加工。家电玻璃包括彩晶、镀膜、层架及盖板玻璃，用于冰箱、洗衣机、空调和厨电；新能源玻璃现阶段以建筑光伏一体化（BIPV）玻璃为主，用于建筑立面、屋面等场景。

### 主要靠什么获得收入？

2025年营业收入16.68亿元，玻璃制品占98.64%，其他占1.36%。出口占41.76%，内销占58.24%，全部收入采用直接销售模式。收入表没有把玻璃制品进一步拆成家电和BIPV金额，不能把98.64%全部称作光伏玻璃收入。
