# *ST同辉 · 公司生意笔记

[← 公司目录](README.md) · `920090.BJ`

同辉信息的业务从商用投影设备等销售，转向数字化场景解决方案。2025年收入主要来自方案交付。

## 生意概览

资料日期：2026-04-22。

### 公司卖什么，解决什么问题？

公司把数字显示、虚拟现实、声音和软件系统组合起来，为教育、金融等机构客户提供数字展厅、控制中心、虚拟实训等场景解决方案，也开展数据中心系统集成等业务。服务内容包括软件开发、软硬件集成及相关产品销售。

### 主要靠什么获得收入？

2025年营业收入约3332.51万元。其中产品解决方案收入约3330.52万元，按全部营业收入计算约占99.94%；单独列示的产品销售收入约1.98万元。年报说明，部分数据中心设备集成与服务业务采用净额法确认收入，因此营业收入不能等同于相关项目的全部交易金额。
