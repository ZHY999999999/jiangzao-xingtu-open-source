# 弘亚数控 · 公司生意笔记

<sub>补充研究笔记 · 原稿 2026-10-13 · 本次整理 2026-10-16。按历史披露阅读，未经旧版网站内容验收。</sub>

看弘亚数控的生意，就是围绕板式家具生产的封边、钻孔、开料设备与自动化产线，境外占四成。

资料日期：2026-04-28。

## 公司卖什么，解决什么问题？

弘亚数控是家具装备研发、生产、销售及服务的行业领军企业，为家具企业智能化生产提供全系列数控装备、自动化生产线和整厂智能制造一站式解决方案。产品覆盖板式家具、实木家具、木门的开料、封边、钻孔、分拣、包装、研磨、曲面加工等设备及其机器人自动化生产线，以及木门规方四边锯、封边、门锁加工设备。公司在中国和意大利设研发制造基地，与全球130多家经销商合作，业务遍及70多个国家和地区。控股子公司丹齿精工的减速机、高精度齿轮、C轴等精密传动零部件已切入工业机器人、精密机床供应链。

## 主要靠什么获得收入？

2025年营业收入24.29亿元，同比下降9.84%。封边机占30.24%，数控钻（含多排钻）占23.04%，加工中心占15.78%，裁板锯占12.36%，配件占8.81%，自动化、木门设备及机器人占7.12%。境外收入占40.09%，同比增长6.46%，境内下降18.22%。

## 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 板式家具厂需要封边工艺 | 制造封边机系列设备 | 取得封边机销售收入 |
| 家具厂需要孔位与裁切加工 | 制造数控钻、裁板锯与加工中心 | 取得钻孔与开料设备销售收入 |
| 家具厂需要整线智能化 | 提供自动化产线与木门设备、机器人 | 取得自动化产线收入 |
| 机器人与机床厂需要精密传动件 | 制造减速机、齿轮与C轴 | 取得精密传动件收入 |

封边机、数控钻、加工中心、裁板锯四大单品占八成一；境内收缩、境外稳增，境外已占四成；自动化与机器人产线增长31.6%是少有的亮点。
