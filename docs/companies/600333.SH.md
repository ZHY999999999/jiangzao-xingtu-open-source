# 长春燃气 · 公司生意笔记

[← 公司目录](README.md) · [行业入口](../industries/README.md) · `600333.SH`

<sub>补充研究笔记 · 原稿 2026-10-13 · 本次整理 2026-10-16。按历史披露阅读，未经旧版网站内容验收。</sub>

长春燃气在吉林省长春市及周边区域拥有长期管道燃气特许经营权，主要向上游采购天然气，经城市管网向居民和工商业用户供气，并提供燃气工程安装服务，同时发展气电结合供暖等综合能源与延伸业务。2025年公司实现营业收入24.62亿元，天然气销气量5.49亿立方米。

资料日期：2026-04-24。

## 公司卖什么，解决什么问题？

公司在长春市及周边区域经营城市管道燃气：向上游多方采购气源，经管网向居民和工商业用户供应天然气，解决炊事、采暖与生产用能需要；同时提供燃气工程安装（设计、施工、监理配套），并发展以“燃气锅炉+空气能”多能耦合的气电结合供暖等综合能源业务，以及智慧厨房、保险、厨房美装等面向终端用户的延伸业务。2025年新开栓供气3.11万户，燃气用户总数183.35万户。

## 主要靠什么获得收入？

2025年营业收入24.62亿元（利润表营业收入2,461,800,027.64元）。按产品口径：燃气销售16.96亿元（约占营业收入68.9%）、燃气安装4.67亿元（约19.0%）、其他2.99亿元（约12.2%）。也就是说，近七成收入来自卖气本身，燃气安装约两成，其余为综合能源、延伸业务等其他收入。

“其他”收入12.2%含综合能源、延伸业务等，年报未再细分；分产品合计与营业收入一致，均为24.62亿元。
