# 飞天诚信 · 公司生意笔记

[← 公司目录](README.md) · `300386.SZ`

飞天诚信为银行及其他行业客户提供身份识别、交易安全和支付相关产品与方案。2025年，身份认证和智能终端是收入规模相近的两条主线。

## 生意概览

资料日期：2026-04-15。

### 公司卖什么，解决什么问题？

它提供USB Key、动态口令和令牌等身份认证产品，也提供智能支付终端、安全芯片及相关数字安全解决方案，服务于金融、政府、电信等行业。
