# 格力电器 · 公司生意笔记

[← 公司目录](README.md) · `000651.SZ`

格力从家用和商用空调延伸到其他家电、工业部件和装备；2025年的收入仍主要来自消费电器。

## 生意概览

资料日期：2026-04-29。

### 公司卖什么，解决什么问题？

公司研发、制造和销售家用空调、暖通设备、冰箱、洗衣机及其他家电，为家庭和商用场景提供产品与楼宇系统方案。工业侧还经营电机、压缩机、基础材料、工业储能、数控机床和机器人等产品，通过自身制造与销售服务网络交付。

### 主要靠什么获得收入？

2025年营业收入为1704.47亿元，消费电器占78.06%，工业制品及绿色能源占10.20%，智能装备占0.40%，其他主营占1.56%，其他业务占9.78%。这里的分母是营业收入，不是报告另列的1711.18亿元营业总收入；消费电器也不等于空调单一品类。
