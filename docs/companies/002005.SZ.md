# 德豪润达 · 公司生意笔记

[← 公司目录](README.md) · `002005.SZ`

德豪润达有两条主要业务线：面向海外客户及国内市场的小家电，以及用于车灯、手机和显示等场景的LED器件。

## 生意概览

资料日期：2026-04-28。

### 公司卖什么，解决什么问题？

公司经营以智能咖啡机为主的厨房小家电，产品还包括电烤箱、面包机、搅拌机等。小家电主要采用OEM、ODM模式向海外客户供货，同时经营国内品牌业务。另一主业是LED封装，产品用于汽车照明、手机闪光灯、电视背光及消费电子。

### 主要靠什么获得收入？

2025年营业收入6.63亿元。按产品分类，厨房家电占52.70%，LED芯片及应用占38.43%，主营业务其他收入占5.54%，其他业务占3.33%。小家电和LED共同构成收入主体；按行业划分的小家电53.02%、LED43.65%属于另一套分类，不能与产品比例交叉相加。

**002005-Q3-C001 · 整理理解**

海外小家电客户通过OEM或ODM合作取得厨房电器，公司研发制造并交付产品；国内另有自有及合作品牌业务。LED业务向汽车照明、移动终端和显示等产业链提供封装器件，形成相应产品销售收入。
