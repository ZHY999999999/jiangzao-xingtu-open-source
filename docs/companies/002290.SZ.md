# 禾盛新材 · 公司生意笔记

[← 公司目录](README.md) · `002290.SZ`

禾盛为家电制造商提供外观板材，也通过海曦技术经营人工智能软硬件和系统服务。

## 生意概览

资料日期：2026-03-27。

### 公司卖什么，解决什么问题？

公司研发、生产和销售家电外观复合材料PCM、VCM，应用于冰箱、洗衣机、热水器、微波炉等产品外壳或面板。另一业务由海曦技术开展，围绕国产人工智能芯片提供相关软硬件设计、研发、销售及运维。

### 主要靠什么获得收入？

2025年营业收入25.55亿元。家电复合材料占96.89%，人工智能及系统集成板块占1.35%，其他占1.76%。人工智能业务虽已形成收入，但这一年的收入主体仍是家电材料，不能用新业务标签替代实际收入结构。
