# 天地数码 · 公司生意笔记

[← 公司目录](README.md) · `300743.SZ`

天地数码供应的是打印耗材。热转印打印时，碳带上的油墨在热和压力作用下转移到标签等介质上，用于物流、制造、零售等场景中的标识和追溯。

## 生意概览

资料日期：2026-04-21。

### 公司卖什么，解决什么问题？

它研发、生产和销售热转印碳带，包括条码碳带、传真碳带、打码碳带、水转印碳带等。条码碳带是主要产品，供条码和标签打印机使用；它卖的是耗材，不能把这项业务理解成销售打印机。

### 主要靠什么获得收入？

2025年，条码碳带占营业收入88.06%，是最主要的收入来源；其他收入占10.48%，传真、打码及水转印碳带合计规模较小。热转印碳带的行业口径已经包含上述几类碳带，不能再与产品分类相加。
