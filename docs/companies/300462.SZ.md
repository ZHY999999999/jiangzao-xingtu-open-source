# ST华铭 · 公司生意笔记

[← 公司目录](README.md) · `300462.SZ`

华铭有三条主要业务：轨道交通自动售检票系统、道路交通ETC产品和热管理设备。它主要向机构和设备厂商交付产品与系统，服务乘客并不等于直接赚取乘客票款。

## 生意概览

资料日期：2026-04-27。

### 公司卖什么，解决什么问题？

它研发、制造和销售自动售检票终端并做系统集成，供应ETC路侧和车载产品，也向商用车、工程机械、轨道交通及储能等客户提供热管理设备和技术服务。

### 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 需要自动售检票系统的轨道交通等项目建设单位。 | 研发制造售检票设备，开发并集成系统，完成供货和技术服务。 | 取得AFC设备和技术服务收入。 |
| 采购ETC产品的集成商、高速公路联网机构及银行等。 | 组织生产与外协加工，完成ETC产品组装、检验和交付。 | 取得ETC产品及相关维修服务收入。 |
| 需要温度控制系统的车辆、工程机械、轨道交通及储能设备客户。 | 开发、生产并交付热管理设备，提供配套技术和维修服务。 | 取得热管理产品销售及相关服务收入。 |

占比采用分产品表。热管理产品收入为173480317.63元，行业分类中的同类名称金额略有不同，两种分类不混用。
