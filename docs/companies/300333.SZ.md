# 兆日科技 · 公司生意笔记

[← 公司目录](README.md) · `300333.SZ`

兆日科技的主要生意围绕银行对公业务：销售电子支付密码器等票据防伪产品，为银行建设银企通系统，也研发纸纹防伪产品。

## 生意概览

资料日期：2026-04-24。

### 公司卖什么，解决什么问题？

公司提供电子支付密码器系统及密码芯片、银企通对公业务平台，以及纸纹核验设备和相关软件。主要客户是银行，产品也用于银行对公开户企业；银企通按银行需求实施交付，纸纹防伪则面向票据及商品防伪等应用。

### 主要靠什么获得收入？

2025年营业收入为1.28亿元。电子支付密码器系统占86.32%，银企通系统占10.35%，纸纹防伪系统占0.07%，其他占3.26%。主要收入仍来自传统密码器系统，不能因纸纹防伪应用场景较多，就把它视作当年的主要收入来源。

### 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 直接采购产品的银行等客户 | 交付密码器等金融安全产品 | 取得产品销售收入 |
| 通过银行网点购买的对公开户企业 | 银行代销公司的相关产品 | 银行按销售清单与公司结算，公司确认销售收入 |
| 需要定制对公业务系统的银行 | 按银行需求开发、交付系统 | 收取系统建设费用 |

银行既可能是直接客户，也可能是代销渠道；代销费是公司向渠道支付的费用，不能当作公司收取的收入。
