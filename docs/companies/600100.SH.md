# 同方股份 · 公司生意笔记

[← 公司目录](README.md) · `600100.SH`

同方股份的主要生意有三条：给机场、海关等客户提供安检系统；通过知网等平台提供知识与软件服务；给供暖、园区等场景提供能源设备、工程和运维。

## 生意概览

资料日期：2026-04-29。

### 公司卖什么，解决什么问题？

同方股份既卖设备，也做软件和工程服务。公共安全业务提供行李、货物和车辆等检查系统；数智业务包含知网数据库、知识管理以及面向政府和企业的软件开发；智慧能源业务提供热泵、储能和能源管理系统，并承担工程建设、节能服务与运维。

### 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 机场、海关、交通与物流等场景需要检查人员、行李、货物和车辆 | 提供智能安检设备、系统方案及后续运维 | 通过检查系统及相关服务取得收入 |
| 机构与个人需要检索知识，政府和企业需要业务软件 | 通过知网等平台提供数据库与知识服务，开发行业软件和解决方案 | 收取机构订阅、个人按需使用及软件开发或授权费用 |
| 供暖、园区、轨道交通等客户需要供热和能源管理 | 提供热泵、储能与控制系统，承担工程建设、节能及运维工作 | 取得设备、工程和服务收入 |

数智业务已受计算机业务转让影响，不能继续把旧电脑硬件规模当作当前集团的业务结构。
