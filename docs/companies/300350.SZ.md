# 华鹏飞 · 公司生意笔记

华鹏飞做全球综合性现代物流服务：为制造业客户和进出口贸易企业提供干线整车运输、零担拼箱、仓储、关务、多式联运、国际货代等全链路物流服务，并为核心客户延伸做代理采购、供应链贸易等供应链管理服务（起辅助配套作用）。2025年组建直属TIR车队，做中国境内到俄罗斯、白俄罗斯、中亚及跨里海直达欧洲的跨境公路运输。2025年营业收入4.60亿元，同比增长37.53%，其中国内综合物流服务占63.52%、国际物流服务占31.33%。但收入高增的同时利润转亏：归母净利润-3,602.18万元，扣非归母净利润-699.94万元。

资料日期：2026-04-27。

## 公司卖什么，解决什么问题？

华鹏飞帮制造业客户和进出口贸易企业解决货物的国内运输和跨境流通问题。它的全球综合物流解决方案包括方案设计、运输、仓储、装卸、关务、转运、多式联运、国际货代及配送和信息处理等全链路服务，分两种服务模式：干线整车运输（为大批量、高价值货物托运人提供端到端、门到门的合同制物流）和零担拼箱运输（把小批量货物集货拼装成整车再长途干线运输）。运力上自有高端车队与外协社会物流资源结合，自有车队主要做跨境TIR一车直达运输。供应链管理服务（代理采购、供应链贸易）在整体业务中起辅助配套作用。

## 主要靠什么获得收入？

2025年营业收入4.60亿元，同比增长37.53%。分行业：物流服务业4.55亿元，占98.91%；信息服务业503.13万元，占1.09%。分产品：国内综合物流服务2.92亿元，占63.52%（同比增长48.81%）；国际物流服务1.44亿元，占31.33%（同比增长19.38%）；供应链业务1,865.70万元，占4.06%；智能移动服务503.13万元，占1.09%。

毛利率整体不高：物流服务业毛利率9.90%，其中国内综合物流5.86%、国际物流6.43%。收入增长37.53%的同时公司由盈转亏：2025年归母净利润-3,602.18万元（上年为+1,714.15万元）；扣非归母净利润-699.94万元，虽较上年减亏73.21%，但主业层面已连续亏损（2023、2024年扣非均为负）。归母与扣非之间约2,900万元差异主要来自非流动性资产处置损失（-1,175.95万元）和金融资产公允价值变动及处置损失（-2,392.29万元）等非经常项目。

收入高增长不等于盈利：2025年营业收入同比+37.53%，但归母净利润-3,602.18万元由盈转亏；扣非归母净利润-699.94万元，2023-2025年连续三年扣非为负。

归母净利润与扣非的差异主要由非经常项目构成：2025年非流动性资产处置损益-1,175.95万元、金融资产公允价值变动及处置损益-2,392.29万元，理解亏损结构需区分主业与非经常项。

供应链管理服务是辅助配套业务（2025年占收入4.06%），不是公司收入主体；公司分行业口径下另有信息服务业（智能移动服务）占1.09%。
