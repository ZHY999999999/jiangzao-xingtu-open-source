# 厦门象屿 · 公司生意笔记

<sub>补充研究笔记 · 原稿 2026-10-13 · 本次整理 2026-10-16。按历史披露阅读，未经旧版网站内容验收。</sub>

厦门象屿做的是大宗商品供应链服务：围绕黑色金属、铝、不锈钢、新能源、煤炭、油品、谷物原粮七大品类，为制造业企业采购原辅材料、分销产成品，并配套仓储物流、供应链金融和信息咨询。2025年营业收入4,102.91亿元，同比增长11.90%，其中约九成半来自大宗商品经营与物流；但这是一门极薄利的生意，大宗商品经营毛利率只有1.51%。公司还自建物流体系对外提供市场化物流服务，并切入造船、选矿、油脂加工等生产制造环节。2025年归母净利润12.93亿元，同比下降8.87%；扣非归母净利润17.85亿元，同比增长339.13%。

资料日期：2026-04-24。

## 公司卖什么，解决什么问题？

厦门象屿解决制造业企业的大宗商品供应问题：上游对接矿山、炼厂、农场等资源方，下游服务制造业工厂，提供原材料采购、产成品分销、库存管理、仓储物流、供应链金融、信息咨询的全产业链服务。经营品类聚焦金属矿产（黑色金属、铝、不锈钢）、能源化工（煤炭、油品）、农产品（谷物原粮）、新能源（锂、镍等关键矿产）。公司自述2025年经营货量2.66亿吨，制造业客户服务量占比超60%。在全产业链服务之外，公司还对外提供市场化的大宗商品物流（国际航线、铁路、仓储等），并进入造船（子公司象屿海装，2025年交付28艘、在手订单114艘）、选矿和油脂加工等生产制造环节。

## 主要靠什么获得收入？

2025年营业收入4,102.91亿元，同比增长11.90%。分行业看：大宗商品经营与物流3,969.15亿元（毛利率1.71%），其中大宗商品经营3,852.00亿元、大宗商品物流117.15亿元；其他（生产制造等）127.33亿元（毛利率11.72%）。在大宗商品经营内部按产品分：金属矿产2,141.27亿元（约55.6%）、能源化工1,030.62亿元（约26.8%）、农产品471.53亿元（约12.2%）、新能源181.27亿元（约4.7%）。

必须强调收入不等于利润：大宗商品经营毛利率仅1.51%，4,103亿元的收入对应的归母净利润只有12.93亿元（同比下降8.87%），扣非归母净利润17.85亿元（同比增长339.13%）。归母净利润中包含归属永续债持有人的利息5.07亿元，扣除后为7.86亿元。另外，第四季度归母净利润为负，公司说明系期货套保的期货端亏损已记入当期报表、现货端利润尚未确认所致。

口径提醒：年报'主营业务分产品'表仅指大宗商品经营的收入（3,852.00亿元），不含大宗商品物流和生产制造；分行业合计（4,096.48亿元）与合并营业收入（4,102.91亿元）之间还有少量其他业务，几套数字不可互换。

收入规模不等于盈利水平：大宗商品经营毛利率1.51%；归母净利润12.93亿元中含永续债利息5.07亿元，扣除后为7.86亿元。

2025年第四季度归母净利润为负（-3.40亿元），公司说明系期货套保对应的期货端亏损已记入当期报表、现货端利润尚未确认；扣非与归母的同比大幅背离也与上年同期计提历史事项信用减值等因素有关。
