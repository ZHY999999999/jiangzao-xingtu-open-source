# 雄帝科技 · 公司生意笔记

[← 公司目录](README.md) · `300546.SZ`

雄帝科技围绕身份信息和出行场景，向政府及企业提供证照制作、信息采集核验、公交支付与管理等设备和系统。2025年的主要收入来自数字身份与安全。

## 生意概览

资料日期：2026-04-22。

### 公司卖什么，解决什么问题？

它提供护照等安全证照的制发装备、自助服务和信息采集核验终端，也提供公交支付终端、清分结算及运营管理等系统与服务。

### 主要靠什么获得收入？
