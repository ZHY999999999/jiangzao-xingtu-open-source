# 深圳燃气 · 公司生意笔记

深圳燃气以城市管道燃气为主业，在广东、广西、江西、安徽等11省（区）58个城市（区）经营管道燃气特许经营项目，向居民、工商业和电厂用户销售管道燃气并提供安装服务，同时经营液化天然气与液化石油气批发、光伏胶膜、天然气发电等业务。2025年公司实现营业收入298.01亿元，天然气销售量66.65亿立方米。

资料日期：2026-03-31。

## 公司卖什么，解决什么问题？

公司业务分四大板块：城市燃气、燃气资源、综合能源、智慧服务。城市燃气是核心：在特许经营区域内向城市居民、工商业和电厂等用户销售管道燃气，气源主要从中石油、中石化、中海油、广东大鹏及国际资源供应商等采购，同时为用户安装燃气设施和天然气管道，收取设计和安装费用。燃气资源业务是统筹采购液化天然气和液化石油气，通过槽车、槽船或管道批发给客户。综合能源业务包括控股子公司江苏斯威克生产销售光伏封装胶膜、深燃热电购天然气发电并供热，以及光伏、节能等综合供能。智慧服务业务包括燃气输配设备、物联网燃气表、自主品牌燃气具和管道安全检测服务等。

## 主要靠什么获得收入？

2025年营业收入298.01亿元。按主营业务分产品口径：城市管道燃气156.69亿元（约占营业收入52.6%）、天然气批发及其他50.81亿元（约17.0%）、光伏胶膜36.64亿元（约12.3%）、发电业务17.37亿元（约5.8%）、燃气工程及其他13.49亿元（约4.5%）、石油气批发10.30亿元（约3.5%）、商品销售及其他10.78亿元（约3.6%）。也就是说，收入基本盘是向居民和工商业用户卖管道燃气，天然气批发和光伏胶膜是另外两块重要来源。

**601139-Q1-C001 · 公司表述**

公司业务分为城市燃气、燃气资源、综合能源、智慧服务四大板块。城市管道燃气业务为特许经营业务，主要向城市居民、工商业和电厂等用户销售管道燃气，截至2025年末已在广东、广西、江西、安徽、江苏、浙江、云南、湖南、湖北、河北等11省（区）经营58个城市（区）管道燃气项目，在深圳地区主要从中石油、中石化、广东大鹏以及国际资源供应商等气源方采购天然气；燃气工程业务为居民及工商业用户提供燃气设施、设备、安装天然气管道等服务，并收取设计和安装费用。燃气资源业务由液化天然气及液化石油气批发业务组成，通过槽车、槽船或管道销售给客户。综合能源业务包括控股子公司江苏斯威克的光伏胶膜研发生产销售、深燃热电购入天然气发电并供热、以及光伏等新能源综合供能。智慧服务业务拥有燃气输配设备、物联网燃气表、自主品牌燃气具、管道安全技术服务等核心业务。

**601139-Q3-C001 · 整理理解**

公司城市燃气业务从上游气源方采购天然气，经城市输配管网向居民、工商业和电厂等终端用户供气，终端销售价格及相关服务价格受经营区域所在地政府物价部门核定或监管；2025年公司天然气用户达到877.65万户，天然气销售量66.65亿立方米。
