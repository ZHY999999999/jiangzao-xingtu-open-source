# 中安科 · 公司生意笔记

中安科的业务分三块：境外安保综合运营——通过香港卫安、澳门卫安、泰国卫安为银行、机场、零售商业等提供武装押运、人力安防和电子安防服务，香港市场份额居全港第一；智慧城市系统集成——面向国内做智慧交通、智慧医疗、网络信息安全（信创涉密）工程；智能安防产品制造——子公司常州明景、深圳豪恩、深圳科松生产视频监控、物联传感器、门禁道闸等产品。2025年营业收入30.70亿元，同比增长0.63%；归母净利润5,296.01万元，同比增长164.41%，但增长主要来自债务重组收益，扣非归母净利润为-1.47亿元（资产减值损失增加）。公司未弥补亏损已达实收股本总额的三分之一。

资料日期：2026-04-17。

## 公司卖什么，解决什么问题？

中安科解决三类安全问题：一是人身与财产安全——境外子公司为港澳泰的公共服务机构、机场、银行、零售商提供武装押运、人力安保、电子安防和机场配套服务（'卫安Guardforce'品牌，香港卫安1977年成立、市场份额全港第一）；二是城市运行的'工业安全'——在内地做智慧交通、智慧医疗（医院信息化、医疗洁净与实验室系统工程）、网络信息安全（信创+涉密+安全）的系统集成工程；三是安防硬件——研发生产视频监控前端、电力AI巡检、物联传感器、报警设备、门禁道闸等产品，应用于公安、交通、能源、医院等行业。

## 主要靠什么获得收入？

2025年营业收入30.70亿元，同比增长0.63%。分行业看：安保运营20.23亿元（占65.90%），毛利率17.57%；安防（系统集成与制造）10.32亿元（占33.61%），毛利率8.70%；租赁0.13亿元；其他0.02亿元。分产品看：安保运营服务20.23亿元、安保系统集成8.25亿元（毛利率仅4.39%）、安保智能产品制造2.07亿元（毛利率25.90%）。境外安保综合运营业务收入19.71亿元，同比增长5.23%，是收入主体。

2025年归母净利润5,296.01万元，同比增长164.41%，但公司说明增长主要系通过法院结案等方式推动债务化解产生的债务重组收益；扣非归母净利润为-1.47亿元，亏损扩大33.69%，公司说明系资产减值损失增加所致。也就是说，报表盈利而主业实际亏损；公司未弥补亏损已达实收股本总额的三分之一。

报表盈利但主业亏损：2025年归母净利润5,296.01万元主要来自债务重组收益（非经常性），扣非归母净利润-1.47亿元；公司披露未弥补亏损达实收股本总额三分之一。

分行业'安防'（10.32亿元）包含分产品口径的'安保系统集成'（8.25亿元）与'安保智能产品制造'（2.07亿元）等，两套口径是包含关系而非并列关系，不可混用。

利润季节波动大：2025年第三季度归母净利润1.95亿元（债务重组收益确认），第四季度-1.45亿元（资产减值损失），单季数据不宜线性外推。
