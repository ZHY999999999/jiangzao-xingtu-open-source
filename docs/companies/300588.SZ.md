# 熙菱信息 · 公司生意笔记

[← 公司目录](README.md) · `300588.SZ`

熙菱把数据接入、治理、分析和应用开发组合成项目，帮助客户建设数字化业务系统；另一类工作是网络和数据安全测评。2025年收购北京资采后，通信运营商软件服务成为最大的收入类别。

## 生意概览

资料日期：2026-04-29。

### 公司卖什么，解决什么问题？

它为政府、企业和通信运营商开发软件与数字化方案，覆盖公共安全、政务及企业业务；还为政府、金融、教育、医疗等客户提供网络和数据安全测评、咨询服务。

### 主要靠什么获得收入？

2025年，通信运营商软件开发及服务占营业收入44.75%，智能安防及信息化工程占23.35%，信息安全产品、服务与方案占20.04%，其他数字政府及企业服务与方案占11.80%。北京资采自2025年1月纳入合并报表，通信运营商软件服务是当年新增收入类别，不能把收入增长全部理解为原有业务自然增长。
