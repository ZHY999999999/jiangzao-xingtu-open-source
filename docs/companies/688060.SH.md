# 云涌科技 · 公司生意笔记

[← 公司目录](README.md) · `688060.SH`

云涌科技主要给工业领域的技术服务商和设备商提供通信网关、安全设备及软件，让电力、能源等场景中的设备能安全地连接、传输和处理数据。

## 生意概览

资料日期：2026-04-24。

### 公司卖什么，解决什么问题？

云涌科技研发、生产和销售工业信息安全产品。通信网关负责连接设备、采集与传送信息，安全感知和加密产品帮助识别风险、保护数据，国产化平台产品供客户集成使用。公司还做智能档案柜及控制类产品。多数客户会把买来的产品集成或再次开发，再交付给最终用户。

### 主要靠什么获得收入？

2025年，工业安全通信网关设备贡献了约一半的收入，是最大的产品线；工业安全态势感知设备和国产化平台通用产品排在后面，另有智能档案柜及控制类产品、信息安全加密产品。部分新能源业务计在安全感知设备里，不能另加一遍。
