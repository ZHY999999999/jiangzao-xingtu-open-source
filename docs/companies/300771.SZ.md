# 智莱科技 · 公司生意笔记

[← 公司目录](README.md) · `300771.SZ`

智莱把柜体、电子控制和软件组合成设备，帮助客户完成物品保管、交付、售卖或换电。它的主要收入来自智能快件箱设备，不能将设备销售直接理解为每次寄取快递的收费。

## 生意概览

资料日期：2026-04-10。

### 公司卖什么，解决什么问题？

它提供智能快件箱、电子寄存柜、恒温及售卖设备、智慧医疗设备、换电柜和其他定制智能交互设备。主要快件箱业务按企业客户需求设计、生产、运输、安装和调试，随后由客户以自己的品牌运营。

### 主要靠什么获得收入？

2025年，智能快件箱类设备占营业收入61.09%，是最大的收入来源；智能换电柜类设备占9.51%，恒温及售卖类设备占7.78%，电子寄存柜类设备占6.52%。其他收入占12.47%，不能仅凭这项分类把它全部归为柜机运营收费。
