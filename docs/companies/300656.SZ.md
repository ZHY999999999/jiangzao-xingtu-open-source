# 民德电子 · 公司生意笔记

[← 公司目录](README.md) · `300656.SZ`

民德有几种不同的工作：研发和供应识读、数据采集设备，为芯片设计公司代工功率半导体晶圆，也设计功率器件并经营电子元器件分销。

## 生意概览

资料日期：2026-08-15。

### 公司卖什么，解决什么问题？

它销售条码识读、机器视觉和自动化数据采集设备，也通过子公司开展功率半导体晶圆代工、器件设计及电子元器件分销。晶圆代工是为设计公司制造晶圆，器件设计业务则委托代工厂生产，两者不能混成一种制造方式。

### 主要靠什么获得收入？

2026年上半年，按报告中的产品收入金额计算，信息识别及自动化产品约占营业收入42.11%，功率半导体产品约占35.60%，电子元器件产品约占22.29%。这些是半年数据；君安技术在2025年11月被转让后不再纳入合并报表，同比口径发生了变化。

### 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 需要识读条码、获取图像或自动采集数据的设备商、集成商和用户。 | 自主设计设备，组织委外加工并完成总装、测试和供货。 | 取得信息识别及自动化产品收入。 |
| 需要功率器件的设计公司、封测厂、分销商和终端客户。 | 分别开展晶圆定制代工，以及器件设计、委托生产和销售。 | 取得功率半导体产品相关收入。 |
| 需要采购电子元器件的客户。 | 开展电子元器件分销，完成采购与销售。 | 取得电子元器件产品销售收入。 |

收入比例由2026年半年报产品金额除以同期全部营业收入计算；功率半导体中代工与设计两种业务没有在该表分别列出占比。
