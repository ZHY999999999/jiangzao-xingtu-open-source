# 汉邦高科 · 公司生意笔记

[← 公司目录](README.md) · `300449.SZ`

汉邦高科既为政企客户交付服务器、算力集群及配套服务，也经营广电音视频监测和音视频产品。2025年的主要收入来自智算服务解决方案。

## 生意概览

资料日期：2026-04-28。

### 公司卖什么，解决什么问题？

它提供服务器供货、算力集群部署、系统集成、调试和运维等智算服务，也提供广电音视频监测方案、摄像与存储等音视频产品，并布局数字水印与内容安全业务。
