# 工业富联 · 公司生意笔记

[← 公司目录](README.md) · `601138.SH`

服务器负责计算，存储设备保存数据，网络设备让数据流通。工业富联为企业客户研发和制造这些硬件，也生产手机等终端里的精密结构零件。

资料口径：2025完整年度；经营形态补核2026半年度。收入构成仍采用2025年度。

## 财务阅读

### 收入和利润一起扩大

报告期：2025-12-31

2025年营业收入9028.87亿元，同比增长48.22%；归母净利润352.86亿元，同比增长51.99%。这些是全年累计值。

怎样理解：公司一年交付的业务规模和归属于母公司股东的利润都增长了。

理解边界：两者的增长不能单独说明每一种产品都增长，也不能证明每一笔订单都更赚钱。

[工业富联2025年年度报告 · 第9–10页，主要会计数据及变动说明；第17页，主要经营情况](https://static.cninfo.com.cn/finalpage/2026-03-11/1225004420.PDF)

### 增长主要看云计算这一块

报告期：2025-12-31

云计算收入同比增长88.70%；通信及移动网络设备增长3.46%；工业互联网下降26.15%。

怎样理解：同一家公司里的业务并非同速增长。公司披露AI相关业务占比提升，是云计算变化的重要背景。

理解边界：“云计算”包含多种产品，不能把整个分部收入都算成AI服务器收入。
