# 速达股份 · 公司生意笔记

看速达股份的生意，先看围绕煤矿液压支架的维修再制造与备件服务，再看二手设备租售和流体连接件产品。

资料日期：2026-03-31。

## 公司卖什么，解决什么问题？

速达股份专注机械设备的全寿命周期管理，为工业客户提供综合后市场服务，分为五类：维修与再制造，把废旧综采设备修复到性能不亚于新设备；备品配件供应管理，为煤炭企业提供一站式备件供应；专业化总包服务，按采煤量等工作量结算的一揽子维护保养服务；二手设备租售，收购或承租二手设备维修技改后再销售或出租；流体连接件，向煤炭综采设备和工程机械设备生产商供应液压软管、硬管总成。业务主要围绕综采设备中价值占比最高的液压支架开展。

## 主要靠什么获得收入？

2025年营业收入10.62亿元，同比下降9.01%。维修与再制造占32.29%，备品配件供应管理占23.16%，流体连接件占20.11%，二手设备租售占17.90%，专业化总包服务占5.88%。收入全部来自境内。

## 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 煤矿需要维持综采设备运转 | 维修与再制造废旧液压支架等设备 | 取得维修与再制造服务收入 |
| 煤矿需要持续的备件与保养 | 提供备件供应管理和按采煤量结算的总包服务 | 取得备件与总包服务收入 |
| 煤矿希望降低设备投入 | 租售维修技改后的二手设备 | 取得二手设备租售收入 |
| 煤机与工程机械厂商需要液压管路 | 制造软管、硬管总成等流体连接件 | 取得流体连接件销售收入 |

四项服务与一类产品的客户都主要在煤炭产业链；煤价低迷期备件业务下滑36%，二手设备租售和流体连接件分别增长18%和19%，结构在变化。
