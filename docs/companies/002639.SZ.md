# 雪人集团 · 公司生意笔记

<sub>补充研究笔记 · 原稿 2026-10-13 · 本次整理 2026-10-16。按历史披露阅读，未经旧版网站内容验收。</sub>

看雪人股份的生意，核心是压缩机（组）与制冰设备，另有油气技术服务和数据中心冷却集成两块。

资料日期：2026-04-28。

## 公司卖什么，解决什么问题？

雪人股份是以热能动力技术为核心的装备制造企业：压缩机（组）及制冰系统业务拥有活塞、螺杆、离心式压缩机技术，制冰系统用于食品加工、商超冷链、混凝土降温、矿井降温、人工冰雪等场景，工商业制冷压缩机覆盖石油化工、食品加工、生物医药、冷链物流、空调热泵及氢能源装备等领域，氨、CO2等天然工质制冷技术处于行业领先；数据中心冷却系统集成为中国移动、联通、阿里系等头部企业的数据中心项目服务；全资子公司佳运油气提供油气开发工程一体化技术服务，中标过中海油LNG接收站开车调试等项目。

## 主要靠什么获得收入？

2025年营业收入25.25亿元，同比增长10.53%。压缩机（组）占42.99%，油气技术服务占28.85%，制冰设备占21.78%，数据中心冷却系统集成占6.04%（同比下降19.85%，公司主动转向头部客户高质量项目）。境外收入占16.80%，同比增长23.10%。

## 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 食品冷链与工业用户需要制冷动力 | 制造压缩机（组）与制冷系统 | 取得压缩机（组）销售收入 |
| 食品、建筑、矿井等需要制冰 | 制造制冰设备与系统 | 取得制冰设备销售收入 |
| 油气公司需要开发工程服务 | 提供油气开发、调试等技术服务 | 取得油气技术服务收入 |
| 数据中心需要冷却系统 | 提供冷却系统集成 | 取得集成项目收入 |

压缩机、油气服务、制冰三块约九成三；数据中心冷却在主动收缩提质。氨、CO2天然工质技术是公司自述的差异化优势。
