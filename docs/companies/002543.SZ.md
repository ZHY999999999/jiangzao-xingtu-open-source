# 万和电气 · 公司生意笔记

[← 公司目录](README.md) · `002543.SZ`

万和的产品服务家庭热水、采暖和厨房需求，国内以自主品牌为核心，海外经营OEM、ODM等业务。

## 生意概览

资料日期：2026-04-28。

### 公司卖什么，解决什么问题？

公司提供燃气热水器、电热水器、燃气采暖炉和空气能热泵等热水采暖产品，也经营厨房电器，向海外拓展取暖器、烤箱和洗碗机等品类。经营方式包括自主品牌、品牌授权以及OEM、ODM设计制造，不能把全部业务都理解为国内热水器零售。

### 主要靠什么获得收入？

2025年营业收入72.29亿元。厨房电器占48.21%，生活热水占45.18%，其他产品占4.18%，综合服务占0.58%，其他非主营业务占1.86%。出口销售占全部营业收入41.66%，属于按销售地区或方式的另一种划分，不能与产品收入相加。

**002543-Q3-C001 · 整理理解**

国内消费者通过品牌及渠道购买热水和厨卫电器，公司研发制造、销售并提供服务。海外客户通过OEM、ODM等方式取得产品，公司承接制造或设计制造订单并交付，形成相应产品销售收入。
