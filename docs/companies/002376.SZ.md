# 新北洋 · 公司生意笔记

[← 公司目录](README.md) · `002376.SZ`

新北洋围绕少人值守和自动化场景销售专用设备，并提供物流分拣运营、设备运维等服务。它的收入分布在多类产品和服务之间。

## 生意概览

资料日期：2026-04-24。

### 公司卖什么，解决什么问题？

它提供专用打印扫描设备、快递柜等智能自助终端、金融机具和物流分拣装备，也开展新零售运营、物流分拣运营、设备运维及零部件业务。
