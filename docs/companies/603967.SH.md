# 中创物流 · 公司生意笔记

[← 公司目录](README.md) · [行业入口](../industries/README.md) · `603967.SH`

<sub>补充研究笔记 · 原稿 2026-10-13 · 本次整理 2026-10-16。按历史披露阅读，未经旧版网站内容验收。</sub>

中创物流主营综合性现代物流，业务分三块：跨境集装箱物流是主体和基本盘，围绕国际集装箱海运提供货运代理、船舶代理、场站仓储、沿海运输、铁路接卸、冷链等服务；工程物流专注核电、风电、石化等领域的超限设备运输，靠自行式模块运输车、液压轴线车、自航驳船等特种装备构建竞争力；资源转运物流围绕矿石等大宗散货，在印尼用自有过驳船队做海上转运（年过驳能力1500万吨），在国内做铁矿石、有色矿的保税堆存、破碎筛分、混矿加工。2025年受国际海运价格下跌影响，营业收入88.52亿元，同比下降25.24%，但归母净利润2.61亿元，同比增长3.22%。

资料日期：2026-03-27。

## 公司卖什么，解决什么问题？

中创物流解决三类物流问题。对进出口贸易商、生产商和同行物流企业，它围绕国际集装箱海运提供货代、船代、场站仓储、沿海运输、铁路接卸、冷链等全链条服务，网络遍及国内主要港口及内陆枢纽，辐射欧美、日韩、东南亚、中东、中亚；对核电、风电、石化等工程业主，它用特种装备运输核燃料组件、压力容器、风电叶片塔筒、大型反应器等超限设备，并通过沙特子公司服务中国企业海外工程项目；对矿石资源商和贸易商，它在印尼用7艘过驳船、3艘驳船做铝土矿、煤炭海上转运（2025年完成印尼煤炭过驳量1566万吨），在国内枢纽港做铁矿石、有色矿的保税堆存、破碎筛分、混矿加工和分拨疏运。

## 主要靠什么获得收入？

2025年营业收入88.52亿元，同比下降25.24%，收入下滑主因是国际海运价格下跌拖累跨境集装箱物流收入。按产品分：跨境集装箱物流77.01亿元，占合并营业收入87.00%，同比下降29.12%，毛利率5.69%；工程物流9.59亿元，占10.83%，同比增长21.21%，毛利率11.30%；资源转运物流1.71亿元，占1.94%，同比增长4.44%，毛利率42.58%。

值得注意的结构细节：收入近九成来自运价敏感的集装箱业务，但利润来源更多元——三块业务毛利额占比分别为69.05%、17.07%、11.50%，毛利率最高的资源转运以不到2%的收入贡献了一成以上毛利。2025年归母净利润2.61亿元（同比增长3.22%），扣非后2.46亿元（同比增长1.35%）：收入大幅下降而利润反而增长，靠的是运价下跌同步压低采购成本、工程物流与资源转运等高毛利业务增长，以及精细化成本管控。

收入同比下降25.24%而净利润同比增长3.22%：收入下降主因是国际海运价格下跌（货代收入与运价挂钩），同期采购的运力成本也下降，且工程物流、资源转运等高毛利业务增长。收入规模与盈利变动方向可以背离。

资源转运物流毛利率42.58%，同比下降10.38个百分点（成本增长27.50%快于收入增长），高毛利水平并非稳定不变。

三项主营业务合计88.31亿元，占合并营业收入的99.77%，其余约0.21亿元为其他业务。
