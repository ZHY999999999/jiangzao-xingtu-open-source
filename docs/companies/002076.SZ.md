# 星光股份 · 公司生意笔记

[← 公司目录](README.md) · `002076.SZ`

星光的交付既有灯具和设备，也有光伏组件、工程与发电服务。这几种收入来自不同的工作。

## 生意概览

资料日期：2026-04-29。

### 公司卖什么，解决什么问题？

公司提供LED照明、汽车照明、紫外线杀菌灯等产品，也向电池制造企业提供锂电制造设备。光伏业务包括组件销售、电站工程和电站运营，此外还有信息安全集成等业务。锂电设备是生产电池所用的设备，不是电池销售。

### 主要靠什么获得收入？

2025年营业收入3.80亿元。其中LED照明占41.87%，锂电设备占20.02%，光伏组件占9.85%，汽车照明占8.24%，紫外线杀菌灯占6.18%。光伏EPC工程占3.24%，光伏运营占0.61%；组件、工程和发电收入不能都称作“卖电收入”。

### 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 客户需要照明、汽车照明或消毒灯 | 研发制造并销售对应灯具产品 | 取得照明等产品销售收入 |
| 电池制造企业需要生产设备 | 按需求设计制造锂电设备并交付 | 取得锂电设备销售收入 |
| 光伏客户需要组件或建设电站 | 供应组件，或完成受托电站工程 | 分别取得组件销售和EPC工程收入 |
| 电网等购电方需要电力 | 运营光伏电站并供电 | 按供电取得光伏运营收入 |

上表中的光伏组件、工程和运营属于不同交付方式，不能用其中一种收入代表全部光伏业务。

**002076-Q3-C001 · 整理理解**

照明客户购买灯具等产品，电池制造客户购买定制生产设备。光伏客户可采购组件，或委托公司完成电站工程；公司经营的光伏电站则通过销售发电量取得收入。
