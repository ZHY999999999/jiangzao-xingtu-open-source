# 奇精机械 · 公司生意笔记

[← 公司目录](README.md) · `603677.SH`

给洗衣机、汽车和电动工具制造商配套精密零部件。

## 生意概览

资料日期：2026-03-27。

### 公司卖什么，解决什么问题？

公司做机械精加工，主要产品包括洗衣机离合器和其他家电零件、汽车零部件、电动工具零部件。它供应的是配套零件，而非洗衣机或汽车整机。

### 主要靠什么获得收入？

2025年营业收入约20.68亿元，其中家电零部件约15.48亿元，占74.87%；汽车零部件约3.27亿元，占15.80%；电动工具零部件约1.29亿元，占6.24%。
