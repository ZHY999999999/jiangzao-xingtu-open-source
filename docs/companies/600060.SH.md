# 海信视像 · 公司生意笔记

## 生意概览

资料日期：2026-03-31。

### 公司卖什么，解决什么问题？

公司销售海信、东芝、Vidda等品牌的电视等智慧显示终端，也经营激光显示、商用显示、云服务、芯片等新显示业务，服务家庭娱乐及商用显示等场景。

### 主要靠什么获得收入？

2025年营业收入约576.79亿元。智慧显示终端收入约449.64亿元，占全部营业收入的77.95%；新显示新业务约84.58亿元，占14.66%。这些是主营表中的主要项目，并非全部收入。

|---|---|---|
