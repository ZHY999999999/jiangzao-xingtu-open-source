# 金海高科 · 公司生意笔记

[← 公司目录](README.md) · `603311.SH`

为家电和交通等产业提供过滤材料、过滤器与风轮。

## 生意概览

资料日期：2026-04-24。

### 公司卖什么，解决什么问题？

公司研发生产空气过滤材料、过滤网、过滤器、风扇、注塑件及组件，应用于家用和商用空调、空气净化、厨房清洁电器，以及汽车等交通设备的过滤系统。

### 主要靠什么获得收入？

2025年营业收入约8.55亿元，其中空气过滤网及网板约3.67亿元，占42.92%；空调风轮及周边产品约3.55亿元，占41.48%；过滤器约1.09亿元，占12.70%。
