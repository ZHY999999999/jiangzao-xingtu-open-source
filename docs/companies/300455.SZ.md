# 航天智装 · 公司生意笔记

[← 公司目录](README.md) · `300455.SZ`

航天智装做的是行业装备：保障列车检测检修，为航空航天等复杂装备提供测试仿真和控制部件，也交付核工业特殊环境的自动化系统。

## 生意概览

资料日期：2026-03-28。

### 公司卖什么，解决什么问题？

它销售铁路车辆安全检测与检修设备、测试仿真系统、微系统及控制部组件，以及用于核工业和特殊环境的机器人、远程操作与自动化装备。

### 主要靠什么获得收入？

2025年，智能测试仿真系统和微系统与控制部组件占营业收入44.07%，核工业及特殊环境智能装备系统占31.31%，铁路检测及检修系统占21.67%，其他占2.95%。44.07%是一组系统与部组件的收入，不能全部称为芯片收入。

### 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 需要列车安全检测和检修系统的铁路与城市轨道交通客户。 | 研发设备，组织制造、装配和调试，提供安装及专业服务。 | 取得铁路检测检修产品与服务收入。 |
| 需要测试、仿真和控制部件的航空航天等装备客户。 | 按需求设计配置测试系统，供应微系统模块及控制部组件。 | 取得测试仿真系统和微系统与控制部组件收入。 |
| 需要在核工业及特殊环境完成操作作业的行业客户。 | 按项目设计加工智能装备，完成总装、系统联调和交付验收。 | 取得核工业及特殊环境智能装备系统收入。 |

这些比例描述收入来源，不代表利润贡献；2025年核工业及特殊环境智能装备系统的毛利率为-33.81%。
