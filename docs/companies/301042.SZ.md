# 安联锐视 · 公司生意笔记

[← 公司目录](README.md) · `301042.SZ`

安联锐视主要做视频监控设备的软硬件研发和制造。摄像机负责采集画面，后端录像机负责接入、保存和调取录像，客户再把这些设备用于家庭、商铺或工程项目。

## 生意概览

资料日期：2026-04-29。

### 公司卖什么，解决什么问题？

它的核心产品是安防视频监控摄像机和硬盘录像机，并为品牌客户提供产品方案、设计研发和生产服务。主要采用自主设计制造模式，也按客户需求定制，服务消费类和工程类安防场景。

### 主要靠什么获得收入？

2025年，安防视频监控产品占营业收入99.48%，服务器业务仅占0.19%，收入仍高度集中于原有安防业务。公司在2025年报中说明，受到美国SDN制裁影响，产品出口受限并拖累收入；新业务布局不能视为已经替代了安防收入。
