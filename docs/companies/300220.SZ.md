# 金运激光 · 公司生意笔记

[← 公司目录](README.md) · [行业入口](../industries/README.md) · `300220.SZ`

<sub>补充研究笔记 · 原稿 2026-10-13 · 本次整理 2026-10-16。按历史披露阅读，未经旧版网站内容验收。</sub>

看金运激光的生意，主体是激光切割、焊接装备，另有少量3D打印和已大幅收缩的IP衍生品业务。

资料日期：2026-04-23。

## 公司卖什么，解决什么问题？

金运激光主营高端数字激光装备制造，分金属激光、柔性非金属激光和激光熔覆三部分：金属激光产品包括平面激光切割机、光纤激光切管机、三维切割机、激光焊接机及自动化产线，用于汽车制造、五金、钣金加工、健身器材、航空航天、工程机械、造船等领域；柔性非金属激光产品包括数码激光模切机、大幅面激光裁床、激光雕刻机等，针对柔性非金属材料加工。海外收入占约66%，通过全球30多家本土化代理商销售。IP衍生品运营业务已收缩至收入的1.16%。

## 主要靠什么获得收入？

2025年营业收入2.52亿元，同比下降8.56%。激光设备制造占77.88%，3D及其他占20.91%，IP衍生品运营占1.16%（同比下降76.29%）。国外占65.81%。收入之外要知道：金属激光业务上半年因国际环境与降价下滑32%，下半年才恢复至上年同期水平；归母净利润仅150.61万元，IP衍生品业务虽已收缩但其亏损对净利润影响仍大。

## 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 金属加工企业需要切割焊接 | 制造金属激光切割机、切管机与焊接机 | 取得金属激光设备销售收入 |
| 柔性材料加工需要激光设备 | 制造模切机、裁床与雕刻机 | 取得柔性激光设备销售收入 |
| 潮玩消费者（已大幅收缩） | 运营IP衍生品 | 取得少量IP衍生品收入（亏损） |

出口占六成六，国际环境与关税政策直接影响订单；公司归母净利润只有150万元量级，激光装备竞争之激烈可见一斑；IP衍生品是历史包袱，还在止血过程中。
