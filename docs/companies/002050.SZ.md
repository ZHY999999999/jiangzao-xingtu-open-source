# 三花智控 · 公司生意笔记

[← 公司目录](README.md) · `002050.SZ`

三花把热管理技术做成阀、换热器、泵等部件，主要供给制冷空调设备和汽车产业。

## 生意概览

资料日期：2026-03-24。

### 公司卖什么，解决什么问题？

公司研发生产热管理控制元器件、子系统和方案，包括电子膨胀阀、四通换向阀、换热器、泵和控制器等，应用于空调、冰箱、制冷及采暖设备。汽车业务提供冷媒和水侧等热管理部件，服务新能源汽车的座舱、电池、电机电控等需求，也供应传统燃油车产品。

### 主要靠什么获得收入？

2025年营业收入310.12亿元，制冷空调电器零部件占59.93%，汽车零部件占40.07%。汽车板块同时包含新能源车与传统燃油车相关产品，不能全部称为新能源车收入；机器人机电执行器属于拓展方向，这张收入表没有单独列出其收入。
