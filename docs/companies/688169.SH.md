# 石头科技 · 公司生意笔记

[← 公司目录](README.md) · `688169.SH`

以扫地机器人为主，销售洗地机等智能家用电器。

## 生意概览

资料日期：2026-04-23。

### 公司卖什么，解决什么问题？

公司设计、研发、生产和销售智能硬件，核心产品是扫地机器人，也有洗地机、智能割草机、洗烘一体机等。

### 主要靠什么获得收入？

2025年营业收入约186.95亿元，其中智能扫地机及配件约151.73亿元，占81.16%；其他智能电器产品约35.07亿元，占18.76%。
