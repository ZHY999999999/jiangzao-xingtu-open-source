# 魅视科技 · 公司生意笔记

[← 公司目录](README.md) · `001229.SZ`

魅视科技为指挥调度、政务和企业等场景提供专业视听产品，并拓展AI视觉分析产品。收入大头仍是专用视听产品。

## 生意概览

资料日期：2026-04-27。

### 公司卖什么，解决什么问题？

它提供软硬件结合的专用视听产品，用于音视频信号的接入、传输、处理和显示调度；也研发AI边缘计算与视觉分析相关产品。
