# *ST瑞茂 · 公司生意笔记

[← 公司目录](README.md) · [行业入口](../industries/README.md) · `600180.SH`

<sub>补充研究笔记 · 原稿 2026-10-13 · 本次整理 2026-10-16。按历史披露阅读，未经旧版网站内容验收。</sub>

*ST瑞茂（瑞茂通供应链管理股份有限公司）的核心生意是煤炭供应链：从国内主产地和印尼、澳大利亚等国际市场组织煤源，卖给电厂等消费端客户，2025年煤炭发运3,609.04万吨、煤炭供应链收入172.28亿元，占营业收入约八成。另有石油化工品贸易（主动缩减中）和大豆进口加工（生产豆油、豆粕）。2025年公司营业收入215.41亿元，同比下降31.61%；归母净利润-31.30亿元，巨亏主要来自应收账款大额信用减值和联营企业亏损按权益法确认的投资损失（-13.76亿元）。因2025年度财报被出具无法表示意见的审计报告、内控被出具否定意见，公司股票被实施退市风险警示并叠加其他风险警示；公司还存在债务逾期、多起诉讼和控股股东股份被轮候冻结事项。

资料日期：2026-04-29。

## 公司卖什么，解决什么问题？

*ST瑞茂解决煤炭等大宗商品的供应组织问题：在煤炭产业链上，向上游煤矿和印尼、澳大利亚等国际市场采购，向下游电力等消费企业销售，提供采购、分销、物流、套期保值等供应链服务，业务覆盖国内主要产销地和二十多个国家和地区的网络。石油化工品业务以现货贸易加期货套保模式操作，2025年因行业下行公司主动缩减规模。农产品业务从国际主产国进口大豆，运到国内工厂压榨成豆油、豆粕销售；但2025年四季度起大豆采购加工业务因经营环境暂无法继续推进，公司计划转为与第三方合作代加工维持基本运转。

## 主要靠什么获得收入？

2025年营业收入215.41亿元，同比下降31.61%。分行业看：供应链管理190.99亿元（毛利率2.34%），其中煤炭供应链管理172.28亿元（占79.98%，毛利率2.56%）、非煤大宗18.71亿元（毛利率0.40%）；农产品加工24.12亿元（毛利率5.81%）；按经营品类口径，农产品业务收入24.08亿元、占营业收入11.18%，两个口径略有差异；产业互联网平台服务0.31亿元（毛利率85.13%）。

收入不等于利润：2025年归母净利润-31.30亿元（上年为+0.67亿元），扣非归母净利润-31.50亿元，期末归母净资产46.47亿元、同比下降41.09%。公司说明亏损主因是：部分子公司及客户涉诉导致应收款项计提较大信用减值损失；部分联营企业大额亏损，按权益法确认投资收益-13.76亿元。亏损高度集中在第四季度（单季归母净利润-32.05亿元）。
