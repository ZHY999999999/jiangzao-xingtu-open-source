# 同有科技 · 公司生意笔记

[← 公司目录](README.md) · `300302.SZ`

同有科技围绕数据存储做生意，产品从企业级存储系统到特殊行业及工业级固态存储，服务客户的数据保存和访问需求。

## 生意概览

资料日期：2026-04-28。

### 公司卖什么，解决什么问题？

公司研发、销售企业级存储系统和固态存储产品，并按行业客户需求提供存储解决方案。产品用于智算、高性能计算等场景，也服务党政、特殊行业、高校科研等客户；交付范围包括部分需要安装调试的项目。

### 主要靠什么获得收入？

2025年营业收入为4.03亿元。存储系统收入占64.25%，固态存储占35.75%，两类构成全年营业收入。按客户分类，政府类用户占92.04%，非政府类用户占7.96%；这是同一收入的另一种分类，不能与产品占比相加。
