# 豪迈科技 · 公司生意笔记

<sub>补充研究笔记 · 原稿 2026-10-13 · 本次整理 2026-10-16。按历史披露阅读，未经旧版网站内容验收。</sub>

看豪迈科技的生意，先看轮胎模具这个老本行，再看大型零部件机械产品和增长1.4倍的数控机床。

资料日期：2026-03-31。

## 公司卖什么，解决什么问题？

豪迈科技主要从事三类业务：子午线轮胎活络模具的生产销售，覆盖乘用胎、载重胎、工程胎、巨型胎模具等，是轮胎硫化成型的关键装备，定位于中高端市场；大型零部件机械产品的铸造及精加工，以风电、燃气轮机等能源类零部件为主，客户包括GE、三菱、西门子、东方电气、上海电气、中车、哈电等，提供从毛坯到成品的一站式服务；机床产品，包括五轴加工中心、车铣复合加工中心、直驱转台等，用于电子信息、汽车制造、精密模具、能源、半导体等行业。

## 主要靠什么获得收入？

2025年营业收入110.78亿元，同比增长25.70%。模具占49.74%，是最大收入；大型零部件机械产品占35.78%；数控机床占8.74%，同比增长142.59%；其他占5.75%。外销占42.07%。

## 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 轮胎厂需要硫化成型模具 | 按单件小批量订单生产活络模具 | 取得模具销售收入 |
| 风电与燃气轮机厂需要大型零部件 | 铸造并精加工能源类零部件 | 取得大型零部件销售收入 |
| 精密制造需要高端机床 | 研发生产五轴加工中心与功能部件 | 取得数控机床销售收入 |

模具和大型零部件合计约八成五，两者毛利率差约18个百分点；数控机床是第三曲线，增速快但占比尚小。
