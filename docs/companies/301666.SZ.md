# 大普微 · 公司生意笔记

[← 公司目录](README.md) · `301666.SZ`

大普微做的是服务器里存放数据的硬盘，主要面向数据中心。它研发控制芯片、固件和整盘方案，委托代工厂组装，再用自己的设备测试交付。

## 生意概览

资料日期：2026-04-29。

### 公司卖什么，解决什么问题？

大普微主要卖企业级固态硬盘，也就是数据中心使用的 SSD。互联网和云计算企业、服务器厂商、电信运营商等客户用它存取数据，关心的不只是容量，还包括读写速度、延迟和长期运行的可靠性。公司还在开发阵列卡、网卡等配套产品。

### 主要靠什么获得收入？

2025年的收入几乎都来自企业级固态硬盘，约占99%。技术服务、阵列卡及其他收入占比较小。因此，理解这家公司的主要生意，应先看它向数据中心客户销售硬盘的过程。
