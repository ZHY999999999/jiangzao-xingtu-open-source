# 微创光电 · 公司生意笔记

[← 公司目录](README.md) · `920198.BJ`

微创光电帮助高速公路运营单位和监管部门看清路况、管理交通，并维护道路机电系统。

## 生意概览

资料日期：2026-04-28。

### 公司卖什么，解决什么问题？

公司提供交通监控产品、智能视频应用及整体解决方案，覆盖路况监测、交通管控、收费查验、服务区数字化和机电运维。除了卖产品，也承接整套系统交付，并提供配套技术服务。

### 主要靠什么获得收入？

2025年营业收入约1.72亿元。按全部营业收入计算，智能交通解决方案约占79.80%，智能视频应用产品约占7.94%，视频监控信息化产品约占6.71%；其余为系统集成、技术服务等。收入重心已是智能交通整体方案。
