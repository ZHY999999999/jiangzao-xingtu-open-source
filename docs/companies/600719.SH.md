# 大连热电 · 公司生意笔记

大连热电主营业务为热电联产、集中供热，产品有电力、工业蒸汽、高温水和供暖四个品种，是大连地区主城区集中供热的主要企业。公司烧煤生产电力与热力，经电网和热力管网对外供电供热，供暖价格由政府定价、电价随电力市场波动。2025年实现合并营业收入6.05亿元，净利润-0.95亿元。

资料日期：2026-03-27。

## 公司卖什么，解决什么问题？

公司为大连主城区提供集中供热并兼营发电，产品有电力、工业蒸汽、高温水和供暖四个品种。经营方式有三类：一是燃煤锅炉烧煤生产热水对外供热；二是热电联产，由所属电厂（北海电厂等）以煤炭为原料生产电力、蒸汽及高温水，经电网和热力管网对外供电供热；三是全资子公司庄河环海自2025年11月起改为外购热量与自供热相结合的供热模式。价格上，供暖由政府物价部门定价，工业蒸汽和高温水协商定价，电价随电力市场交易波动；原料煤炭依靠外部采购。2025年末收费面积1,862.42万平方米。

## 主要靠什么获得收入？

2025年合并营业收入6.05亿元（604,918,718.25元），其中主营业务收入6.01亿元。按产品口径的主营收入：热力收入5.28亿元（约占营业收入87.2%）、电力收入0.71亿元（约11.8%）、其他0.02亿元（约0.4%）。也就是说，收入近九成来自卖热（供暖、蒸汽、高温水），卖电只占约一成。

分产品合计6.01亿元为主营业务口径，与营业收入的差额约383万元为其他业务；热电联产下电与热共用燃煤成本，年报按电、热分别列示收入。
