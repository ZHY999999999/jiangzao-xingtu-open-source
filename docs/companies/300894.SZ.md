# 火星人 · 公司生意笔记

[← 公司目录](README.md) · `300894.SZ`

火星人的交付是把排烟、燃气烹饪和部分蒸烤等功能组合进厨房设备，另有集成洗碗机和水槽等产品。

## 生意概览

资料日期：2026-04-23。

### 公司卖什么，解决什么问题？

公司研发、设计、生产和销售集成灶、集成洗碗机和集成水槽等厨电。集成灶以燃气灶和吸油烟机为核心，不同型号组合蒸、烤、消毒等功能；水洗类产品满足洗碗和厨房用水需求。公司通过经销、直营及电商等方式销售。

### 主要靠什么获得收入？

2025年营业收入7.71亿元。集成灶占83.83%，水洗类产品占8.97%，其他占7.20%。线下渠道占62.14%，线上占37.86%；线上线下是渠道划分，不能再与集成灶等产品收入相加。
