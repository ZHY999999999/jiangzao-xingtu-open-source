# 重庆燃气 · 公司生意笔记

重庆燃气主营业务为重庆市管道燃气供应及燃气设施、设备的安装服务，并发展综合服务、综合能源服务等业务，服务区域覆盖重庆市26个行政区域和湖南保靖县。2025年公司实现销气量35.18亿立方米，营业收入103.05亿元，归属于上市公司股东净利润2.11亿元，期末服务客户数622.65万户。

资料日期：2026-04-17。

## 公司卖什么，解决什么问题？

公司主营业务为重庆市管道燃气供应及燃气设施、设备的安装服务，同时发展综合服务、综合能源服务等业务，其中管道燃气供应及燃气设施、设备的安装服务是核心业务。城镇燃气应用于居民生活、工商业、发电、交通运输、分布式能源等多个领域，公司通过城市燃气输配系统向服务区域内的居民和工商业等客户供气，并为客户提供燃气设施设备的安装接驳，以及安检、维修、户内维修等综合服务。2025年度公司服务区域覆盖重庆市26个行政区域和湖南保靖县。

## 主要靠什么获得收入？

2025年营业收入103.05亿元。主营业务分产品：天然气销售85.40亿元（约占营业收入82.9%）、天然气接驳9.71亿元（约9.4%）。也就是说，收入大头是卖气，接驳（安装接入）约占一成，其余为综合服务、综合能源等其他业务。天然气销售直接购销毛利率14.00%，扣减与销售直接相关的人工、折旧、维护成本后毛利率仅0.34%。
