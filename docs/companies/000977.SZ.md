# 浪潮信息 · 公司生意笔记

[← 公司目录](README.md) · `000977.SZ`

浪潮信息把计算、存储和网络设备交给需要建设数据中心的客户，也提供系统适配、液冷数据中心方案和后续维护。服务器是收入大头。

## 生意概览

资料日期：2026-04-11。

### 公司卖什么，解决什么问题？

它主要生产数据中心使用的服务器，也提供存储、交换类设备，以及围绕这些设备的维护保障和运营维护服务。这些设备用于搭建云计算平台、处理大数据和运行人工智能任务。

### 怎样把产品或服务交付出去？

它先研发计算设备和系统，再与软件伙伴一起适配客户的应用。除了卖设备，公司也提供液冷数据中心从规划设计到建设的整体方案，并提供后续维护；2025年初投运的元脑算力工厂就是按预制化、模块化方式建设的。以境内设备销售为例，按合同送达、客户签收并转移商品控制权后才确认收入；客户已支付或公司已取得收款权但尚未交付的部分记在合同负债里，记下收入和收到现金是两回事。

### 主要成本与风险是什么？

钱主要花在三处。一是已售出设备的成本：2025年服务器产品营业成本约1,476.20亿元，毛利率4.52%，即售价中绝大部分被成本占去。二是研发与日常开支：研发投入约38.77亿元（其中约0.65亿元资本化），销售费用12.72亿元、管理费用9.17亿元。三是备货占住的资金：2025年末存货账面价值465.08亿元，占总资产55.50%；2026年6月底，公司存货总账面价值比上年末增加，需要继续关注这些货何时完成交付。
