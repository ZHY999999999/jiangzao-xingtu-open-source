# 海陆重工 · 公司生意笔记

<sub>补充研究笔记 · 原稿 2026-10-13 · 本次整理 2026-10-16。按历史披露阅读，未经旧版网站内容验收。</sub>

看海陆重工的生意，先看余热锅炉和压力容器两项装备制造，再看增长两倍的核电产品和环保、光伏两项服务运营。

资料日期：2026-03-28。

## 公司卖什么，解决什么问题？

海陆重工的业务分三块：一是装备制造，包括工业余热锅炉（干熄焦、热回收、催化裂化等回收工业余热的节能设备，用于钢铁、有色、焦化、石化等行业）、大型及特种材质压力容器（大型反应器、塔器、换热器、储存容器）和核安全设备（安注箱、堆内构件、一回路主换热器等，用于压水堆、高温气冷堆、聚变堆等）；二是全资子公司格锐环境的工业废水、废气、危废处理及回收利用环境综合治理服务；三是张家港海陆新能源的光伏电站运营，电力自发自用、余电上网或全额上网。

## 主要靠什么获得收入？

2025年营业收入23.22亿元，同比下降16.73%。锅炉及相关配套产品占40.11%，压力容器占28.22%，两项仍是主体；核电产品占13.90%，同比增长257.18%；环保工程与处置类合计约9.6%；新能源电力销售占5.93%。

## 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 钢铁、石化等企业需要回收工业余热 | 按订单制造余热锅炉与压力容器 | 取得锅炉与压力容器销售收入 |
| 核电项目需要核安全级设备 | 制造安注箱、堆内构件等核安全设备 | 取得核电产品销售收入 |
| 工业企业需要废水废气处理 | 提供环保工程设计施工与运营 | 取得环保工程与处置收入 |
| 电网需要电力 | 运营光伏电站售电 | 取得新能源电力销售收入 |

制造、环保服务、售电三块收入逻辑不同；2025年锅炉收入下降而核电产品增长约2.6倍，产品结构在明显切换。
