# 大华股份 · 公司生意笔记

[← 公司目录](README.md) · `002236.SZ`

大华把视频设备、软件和服务组合成方案，服务于城市治理、企业生产和经营等场景；另有机器视觉、移动机器人等创新业务。

## 生意概览

资料日期：2026-04-18。

### 公司卖什么，解决什么问题？

它提供以视频为核心的智慧物联产品与整体方案，服务交通、公共治理及企业生产经营等场景；还经营机器视觉与移动机器人、热成像、汽车电子等业务。
