# 中新赛克 · 公司生意笔记

[← 公司目录](README.md) · `002912.SZ`

中新赛克向政府、运营商和企业提供网络与数据产品，帮助客户了解网络运行、管理数据及保障安全，并提供安装、调试和培训等服务。

## 生意概览
