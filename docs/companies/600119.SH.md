# *ST长投 · 公司生意笔记

[← 公司目录](README.md) · [行业入口](../industries/README.md) · `600119.SH`

<sub>补充研究笔记 · 原稿 2026-10-13 · 本次整理 2026-10-16。按历史披露阅读，未经旧版网站内容验收。</sub>

*ST长投（长发集团长江投资实业股份有限公司）的业务分三块：现代物流（子公司世灏国际做进口商品车报关、仓储、运输，长发国际货运做国际海运货代）、气象科技（子公司长望科技研发生产探空仪、自动气象站等气象探测设备）、长租公寓和产业投资。2025年营业收入2.04亿元，同比大幅下降59.84%，公司说明主要是货代和汽车物流业务收缩所致；归母净利润-4,595.15万元，比上年减亏2,895.86万元。因2025年度经审计财务指标触及财务类强制退市情形，公司股票在年报披露后被实施退市风险警示。

资料日期：2026-04-27。

## 公司卖什么，解决什么问题？

*ST长投通过几家子公司解决三类问题：一是物流——世灏国际为进口商品车（含超豪华汽车）提供报关、仓储和物流运输一站式服务，长发国际货运为进出口企业提供上海、青岛、张家港、太仓等口岸的海运货运代理；二是气象探测——长望科技（新三板挂牌，代码835228）为气象部门和相关行业研发、生产、销售探空仪等高空气象探测设备和风速仪、自动气象站等地面气象仪器，2025年获评国家级专精特新'小巨人'企业；三是长租公寓——长江联合房屋租赁提供租赁管理、物业改造及运营服务，发展集中式住宿和人才公寓。另有长投矿业等资源类投资。

## 主要靠什么获得收入？

2025年营业收入2.04亿元（203,728,891.59元），同比下降59.84%。分行业看：物流及仓储服务1.04亿元（占50.90%），毛利率3.53%；产品销售（气象设备等）0.93亿元（占45.47%），毛利率37.31%；其余为本部及其他收入。按企业口径：物流企业收入1.04亿元占50.91%，气象企业产品销售0.94亿元占46.31%。

2025年归母净利润-4,595.15万元，比上年（-7,491.02万元）减亏2,895.86万元；扣非归母净利润-3,264.64万元。公司说明收入下滑主要是子公司长发国际货运和世灏国际物流销售减少、业务收缩所致。需注意：因2025年度经审计财务指标触及《上海证券交易所股票上市规则》规定的财务类强制退市情形，公司股票在年报披露后被实施退市风险警示；公司披露若2026年度相关财务指标继续触及，股票将可能被终止上市。

退市风险：公司披露2025年度经审计财务指标已触及财务类强制退市情形，年报披露后股票被实施退市风险警示；若2026年度继续触及，股票可能被终止上市。另有金属交易中心诉公司与破产有关的纠纷一案，截至报告披露日尚未判决。

收入连续大幅下滑：2023年8.63亿元、2024年5.07亿元、2025年2.04亿元，公司说明主因是货代和汽车物流业务收缩且未新增业务；2025年末归母净资产仅8,724.52万元，同比下降33.60%。

口径提醒：'分行业'表为主营业务口径（物流及仓储服务+产品销售），与合并营业收入之间存在本部、其他企业及与主营无关收入的差额；物流企业/气象企业口径按经营主体划分，两套口径不可互换。
