# 奔图科技 · 公司生意笔记

[← 公司目录](README.md) · `002180.SZ`

奔图的生意以打印相关产品为主：卖打印机，也卖使用中需要更换的耗材和配件；此外还设计、销售芯片。

## 生意概览

资料日期：2026-08-26。

### 公司卖什么，解决什么问题？

它研发、生产和销售打印机、原装耗材、通用打印耗材及配件，并提供打印管理服务；芯片业务覆盖打印和工业等应用。

### 主要靠什么获得收入？

2026年上半年，通用耗材及配件占营业收入50.58%，原装打印机及耗材占35.52%，芯片占9.40%，其他占4.50%。本期合并范围发生变化，已不包含被处置子公司的收入，不能把同比变化直接当成同一业务范围内的增减。
