# 辰奕智能 · 公司生意笔记

[← 公司目录](README.md) · `301578.SZ`

辰奕把外观、电子电路和嵌入式软硬件组合成遥控器等产品，为家电和智能家居厂商配套。无线遥控器是2025年最大的收入类别。

## 生意概览

资料日期：2026-04-28。

### 公司卖什么，解决什么问题？

它设计、研发、生产和销售红外遥控器、无线遥控器，以及教育产品、智能家居控制器等智能产品。主要按客户订单提供从原型和软硬件设计到制造交付的一体化方案。

### 主要靠什么获得收入？

2025年，无线遥控器占营业收入47.46%，红外遥控器占25.60%，两类遥控器合计占73.06%；其他智能产品占20.94%，其余为教育产品、智能家居控制器及其他收入。按销售模式看，ODM占98.18%，但这不是另一组可额外相加的收入。
