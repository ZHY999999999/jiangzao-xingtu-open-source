# 电科网安 · 公司生意笔记

[← 公司目录](README.md) · `002268.SZ`

电科网安帮助机构保护系统和数据：既卖密码设备、软件和网络安全产品，也提供安全评估、运维等服务。

## 生意概览

资料日期：2026-04-18。

### 公司卖什么，解决什么问题？

它提供密码芯片、模块、软件和设备，以及防火墙、安全运营、数据加密与访问控制等产品和服务，面向政府、金融、能源等机构客户。
