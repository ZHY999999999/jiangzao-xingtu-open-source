# 中国宝安 · 公司生意笔记

[← 公司目录](README.md) · `000009.SZ`

中国宝安是一家多产业集团。贝特瑞的电池材料和马应龙的医药业务，是理解其主要生意的两个入口。

## 生意概览

资料日期：2026-08-29。

### 公司卖什么，解决什么问题？

贝特瑞生产用于新能源汽车动力电池、储能和电子数码的正极、负极材料；马应龙经营药品、医药商业和医疗服务。集团还有汽车与设备所用的精密零件、充电连接器，以及规模较小的房地产等业务。

### 公司卖什么，解决什么问题？

### 怎样把产品或服务交付出去？

集团通过旗下企业开展具体业务。贝特瑞承担电池材料的研发、生产与销售，并做全球采购与产能布局；国际精密制造精密金属零部件，包括液压设备零件和汽车零件；马应龙经营药品生产、医药商业和医疗服务。制造业务交付的是材料或部件，药品和诊疗业务交付的则是药品或服务。货物交付后按条件确认收入，与客户何时付款是两件事。

### 主要成本与风险是什么？

制造业务要买材料、支付人工并维持工厂生产，医药业务也需要原辅材料；集团另外承担研发、销售和管理费用。研发既有当期计入费用的部分，也有符合条件后先计入资产的部分，不能把研发投入与研发费用重复相加。借款利息和汇率变化也会影响财务费用；公司称2025年部分项目投产后，更多利息计入当期费用，叠加汇兑损失增加等因素，推高了这项费用。

### 在产业链里处于什么位置？

它的角色是通过不同企业经营多个产业，而不是把材料、整车、电池和药品都做成同一条生产线。在新能源相关业务中，它提供电池材料、零件和充电连接器；在医药业务中，它参与药品生产经营和医疗服务。因此，看中国宝安既要看主要子公司的生意，也要看集团整体利润，不能把子公司的全部利润都算成中国宝安股东所得。

### 经营发生了什么变化？

2025年，归属于中国宝安股东的净利润约2.03亿元；扣除非经常性损益后，却亏损约0.72亿元，不能只看盈利的那个数。2026年上半年收入同比增长，但归母净利润转为亏损约0.30亿元；公司解释，投资相关收益下降、存货跌价增加，以及部分高新技术子公司的竞争压力和汇兑损失，是主要原因。这两个期间的经营现金流均为正，但现金流与利润并不是同一个指标。上半年数据未经审计，不能拿半年的金额直接与全年作同比。
