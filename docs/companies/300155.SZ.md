# 安居宝 · 公司生意笔记

[← 公司目录](README.md) · `300155.SZ`

安居宝把门口机、室内终端、控制器及软件组合成楼宇与社区系统，另有停车场业务和房屋租赁收入。

## 生意概览

资料日期：2026-04-27。

### 公司卖什么，解决什么问题？

公司研发、生产和销售楼宇对讲、智能家居、停车场、监控等设备与系统。楼宇对讲用于可视通话、开门和门禁联动，智能家居连接家庭设备，停车场系统提供车辆识别、道闸和收费管理等功能。

### 主要靠什么获得收入？

2025年营业收入约1.50亿元。楼宇对讲系统占59.09%，停车场系统及道闸广告业务占10.80%，智能家居占10.79%，房屋经营租赁占10.37%，监控及系统集成占6.04%，其他占2.92%。停车场系统与道闸广告为合并项目，不能把该10.80%全理解为停车费。
