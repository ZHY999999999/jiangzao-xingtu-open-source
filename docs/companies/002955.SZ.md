# 鸿合科技 · 公司生意笔记

[← 公司目录](README.md) · `002955.SZ`

鸿合科技围绕课堂、会议和商业显示提供智能交互产品，主要通过经销渠道销售。交互式显示产品是收入核心。

## 生意概览

资料日期：2026-03-18。

### 公司卖什么，解决什么问题？

它提供智能交互平板、交互式白板等教学与商用显示设备，并配套教学软件、管理平台和智能视听解决方案，用于课堂教学、会议和办公等场景。

### 主要靠什么获得收入？

2025年，年报归入IWB的交互式显示产品占营业收入的72.10%，其他智能交互产品占19.07%，智能视听解决方案占8.83%。按客户应用领域看，教育占79.78%，商用及其他占20.22%。
