# 深物业A · 公司生意笔记

[← 公司目录](README.md) · `000011.SZ`

深物业不仅卖房，还持续维护住宅、园区和公共服务场所，并出租运营办公、商业及居住空间。物业管理是收入最大的业务。

## 生意概览

资料日期：2026-03-28。

### 公司卖什么，解决什么问题？

公司开发住宅、公寓、写字楼和产业园区；通过国贸物业服务住宅、园区、政府机关、轨道交通、医院和学校等场所，并提供水电、电梯等专业服务。它也出租运营空间，提供招商配套，另有餐饮和工程监理业务。

### 主要成本与风险是什么？

物业服务需要投入人员、专业服务和设施运维；房地产开发需要土地、建设等项目投入，公司还承担销售、管理、研发和融资费用。开发中和待售的房产大量体现为存货，即尚未卖出结算的项目资产；它与当期费用、已经支付的现金要分开看。

### 经营发生了什么变化？

2025年，归属于上市公司股东的净利润约3389万元，由亏转盈，但扣除非经常性损益后仍亏约1239万元；同期因资产贬值和欠款可能收不回而确认的损失明显减少。2026年上半年收入增长，却转亏约6818万元，房地产每卖一元收入留下的毛利也明显减少，半年报未经审计。

利润之外还要看回款：2025年经营现金净流出20.86亿元，2026年上半年转为正。开发项目占用资金较大，公司把现金流安全、存量销售和资金回笼列为经营重点。
