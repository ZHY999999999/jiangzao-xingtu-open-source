# 卡莱特 · 公司生意笔记

[← 公司目录](README.md) · `301391.SZ`

卡莱特负责让视频信号正确、清晰地呈现在屏幕上。它主要向LED显示屏厂商供应控制卡、发送器、视频处理器和联网播放器，而不是把整块显示屏都作为自己的产品收入。

## 生意概览

资料日期：2026-04-29。

### 公司卖什么，解决什么问题？

它开发LED显示控制系统、视频处理设备和云联网播放器。发送器和接收卡把视频信号传给LED屏并控制显示，视频处理设备完成拼接、切换和图像处理，联网播放器支持跨区域发布和管理内容。

### 主要靠什么获得收入？

2025年，视频处理设备占营业收入44.58%，接收卡占35.70%，发送器占4.53%，云联网播放器占8.27%，其余为配件及其他业务。接收卡和发送器已属于LED显示控制系统，不能再把系统口径收入额外加上。
