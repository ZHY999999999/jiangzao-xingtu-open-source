# 奥尼电子 · 公司生意笔记

[← 公司目录](README.md) · `301189.SZ`

奥尼的传统业务是摄像机、车载摄像头和无线音频产品等智能终端；2025年高性能计算设备已经形成较大收入，产品延伸到服务器、工作站和个人电脑等。

## 生意概览

资料日期：2026-04-25。

### 公司卖什么，解决什么问题？

它为客户研发制造智能摄像机、车载摄像头、无线音频等产品，也提供AI推理服务器、工作站、AI个人电脑等计算设备与方案。音视频业务以为客户定制设计制造为主，另有自有品牌销售。

### 主要靠什么获得收入？

2025年，音视频智能终端占营业收入62.68%，高性能计算设备占30.79%，其他收入占6.53%。按销售模式看，ODM/OEM占88.03%，自有品牌占10.25%；销售模式与产品分类描述的是同一组收入，不能相加。
