# 顺威股份 · 公司生意笔记

[← 公司目录](README.md) · `002676.SZ`

顺威主要处在整机制造的上游。它按客户要求设计模具和材料配方，制造空调风叶、汽车零部件及工程塑料。

## 生意概览

资料日期：2026-04-15。

### 公司卖什么，解决什么问题？

公司的塑料空调风叶带动空气流过换热器，影响空调的风量、噪声和制冷制热表现。公司还为汽车厂及零部件客户生产内外饰、风机和精密注塑部件，并提供用于汽车、家电等领域的改性塑料。

### 主要靠什么获得收入？

2025年营业收入29.01亿元。塑料空调风叶占55.23%，汽车零部件占24.69%，工程塑料占9.01%，其余为其他产品和其他业务。风叶仍是最大一块，汽车零部件已形成另一项有规模的收入。

### 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 空调厂商需要匹配整机性能的风叶 | 设计配套模具和材料，制造检验塑料风叶 | 取得空调风叶销售收入 |
| 汽车整车和零部件厂商需要塑料功能件 | 开发模具并注塑、加工、装配汽车零部件 | 取得汽车零部件销售收入 |
| 汽车、家电等制造客户需要特定性能材料 | 开发配方并生产改性塑料 | 取得工程塑料销售收入 |

材料、模具和注塑能力服务于产品交付；不是每个内部生产环节都有一笔独立对外收入。
