# 三雄极光 · 公司生意笔记

[← 公司目录](README.md) · `300625.SZ`

三雄极光面向商业、办公、家居及户外场景供给照明产品，国内经销是主要销售方式。

## 生意概览

资料日期：2026-04-25。

### 公司卖什么，解决什么问题？

公司研发、生产和销售LED灯具、光源和照明控制产品，也经营换气扇、浴霸等配套品类。产品用于住宅、商场、写字楼、学校、市政道路等场景；户外工程业务可提供方案设计、产品供应、施工安装到项目交接的一体服务。

### 主要靠什么获得收入？

2025年营业收入18.05亿元。照明灯具占86.40%，照明控制及其他占11.34%，其他占2.26%。按渠道分，经销占87.21%，直销占12.79%；按地区分，国内占98.90%。这些是同一营收的不同分类，不能重复相加。

**300625-Q3-C001 · 整理理解**

家庭和商业等场所需要照明，经销商采购并销售公司灯具；公司也通过电商直接面向消费者。户外工程客户需要完整照明项目，公司自行或合作完成设计、供货和施工，取得相关产品及工程收入。
