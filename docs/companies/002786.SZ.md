# 银宝山新 · 公司生意笔记

<sub>补充研究笔记 · 原稿 2026-10-13 · 本次整理 2026-10-16。按历史披露阅读，未经旧版网站内容验收。</sub>

看银宝山新的生意，基础是模具、塑胶、五金三类制造，战略方向是半导体装备整机；同时它还处于亏损收窄的转型期。

资料日期：2026-04-29。

## 公司卖什么，解决什么问题？

银宝山新以精密模具及结构件为基石，聚焦先进半导体装备领域，提供从研发设计到量产的一站式制造服务。具体包括：精密模具及精密结构件（大型汽车内外饰模具、气体辅助成型模具等，以及汽车保险杠、门板、前端模块、电控箱体等零部件）；通讯终端及消费电子结构件（路由器、机顶盒、基站天线、平板、家电壳体、充电桩结构件等）的注塑、压铸、钣金加工；先进半导体装备整机制造，以高性能焊线机、固晶机、SMT印刷机为核心，提供覆盖快速验证、精密工装、系统集成、功能测试的整机解决方案。

## 主要靠什么获得收入？

2025年营业收入23.03亿元，同比增长3.69%。塑胶产品占39.53%，五金产品占29.82%（同比增长57.00%），模具产品占29.04%，其他占1.61%。境外收入占21.90%，同比增长79.12%。收入结构之外必须知道：2025年归母净利润为-6,321.28万元，仍处亏损但同比收窄76.75%，公司解释为战略转型期的整合成本与盈利水平仍在修复。

## 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 汽车与消费品企业需要成型模具 | 开发精密模具与工装 | 取得模具产品销售收入 |
| 汽车与通讯电子需要塑胶结构件 | 注塑成型与组装零部件 | 取得塑胶产品销售收入 |
| 新能源与装备客户需要金属结构件 | 压铸、钣金、机加五金产品 | 取得五金产品销售收入 |
| 半导体设备商需要整机制造能力 | 提供焊线机、固晶机等整机集成与测试 | 取得装备整机制造收入 |

模具、塑胶、五金三分天下；半导体装备是讲给未来的方向，当前收入拆分里看不到它单独的规模；公司亏损在收窄但尚未扭亏。
