# 智迪科技 · 公司生意笔记

[← 公司目录](README.md) · `301503.SZ`

智迪服务办公和电竞等场景的品牌客户，把客户提出的功能、外观和性能要求变成可量产的键盘、鼠标及套装，客户再使用自己的品牌销售。

## 生意概览

资料日期：2026-04-29。

### 公司卖什么，解决什么问题？

它研发、生产和销售键盘、鼠标等计算机外设，以为品牌客户提供设计制造服务为主。公司按订单组织精密加工、装配和检测，产品覆盖商务办公与电竞游戏场景。
