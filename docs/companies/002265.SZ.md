# 建设工业 · 公司生意笔记

<sub>补充研究笔记 · 原稿 2026-10-13 · 本次整理 2026-10-16。按历史披露阅读，未经旧版网站内容验收。</sub>

看建设工业的生意，分特品（轻型武器装备）和民品（汽车零部件与战略性新兴产业）两块，但军工口径下看不到各自收入。

资料日期：2026-04-23。

## 公司卖什么，解决什么问题？

建设工业有130多年历史，特品主要涵盖轻型武器装备，产品实现谱系、口径、市场三个全覆盖，外贸产品出口全球数十个国家和地区，正推进机械化、信息化、智能化融合。民品主要包括汽车零部件和战略性新兴产业：汽车零部件涵盖转向器、脚踏板、转向轴、中间轴、驱动半轴、连杆、电机轴、商用车钢活塞、减速机齿坯等，与国内一流汽车主机厂和国外零部件供应商长期合作，汽车连杆市场占有率领先；战略性新兴产业涵盖反恐防暴、训练系统、光电信息融合装备、高端钛合金制品、高强度粉末冶金制品等。

## 主要靠什么获得收入？

2025年营业收入45.10亿元，同比增长3.57%。分产品表只拆出主营业务占98.24%、其他业务占1.76%；特品（轻型武器装备）与民品（汽车零部件、战略性新兴产业）各自的收入规模未公开披露，无法从年报构成表看出两块各占多少。

## 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 军方与外贸客户需要轻型武器装备 | 研发生产特种武器装备并出口 | 取得特品销售收入 |
| 汽车主机厂需要转向、传动、动力系统零部件 | 制造转向器、半轴、连杆、电机轴等零部件 | 取得汽车零部件销售收入 |
| 反恐、光电等领域需要新型装备与材料 | 研制训练系统、光电装备、钛合金与粉末冶金制品 | 取得战略性新兴产业收入 |

分产品表只有主营与其他两档，特品与民品各占多少看不到——这是军工企业的披露特点，不是公司没有拆分能力；阅读时应按'军工+汽车零部件双主业'理解，但不填具体比例。
