# 中孚信息 · 公司生意笔记

[← 公司目录](README.md) · `300659.SZ`

中孚帮助机构保护终端、网络和数据：既销售安全软硬件，也提供咨询、测试、应急响应和安全运营等服务。2025年的收入主要来自网络安全产品。

## 生意概览

资料日期：2026-03-31。

### 公司卖什么，解决什么问题？

它提供网络与数据安全产品、密码应用产品、信息安全服务及整体方案，主要面向党政、特殊行业和央国企等机构，覆盖安全防护、监管、检查检测和安全运营等需求。

### 主要靠什么获得收入？

2025年，网络安全产品占营业收入63.28%，信息安全服务占22.28%，其他产品和服务占13.39%；密码应用产品和其他业务规模较小。这里采用全部营业收入作分母，不能再把产品下的子类别收入重复加上。
