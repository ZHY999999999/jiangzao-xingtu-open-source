# 紫光股份 · 公司生意笔记

[← 公司目录](README.md) · `000938.SZ`

紫光股份为政企等客户建设和升级数字基础设施，也开展IT产品分销与供应链服务。阅读收入构成时，需要保留集团内部交易的合并抵消。

## 生意概览

资料日期：2026-04-15。

### 公司卖什么，解决什么问题？

它提供交换机、路由器、服务器、存储、安全和终端等产品，以及云平台和数字化解决方案；另有IT产品分销与供应链服务。

### 主要靠什么获得收入？

2025年，合并营业收入为967.48亿元。按业务披露，ICT基础设施与服务为768.47亿元，IT产品分销与供应链服务为255.62亿元，其他业务为4.81亿元；三项合计还需扣除61.41亿元合并抵消，不能直接相加当成公司总收入。
