# 九阳股份 · 公司生意笔记

[← 公司目录](README.md) · `002242.SZ`

九阳的产品包括食品加工机、营养煲、西式电器和炊具，经线上线下渠道销售。

## 生意概览

资料日期：2026-03-27。

### 公司卖什么，解决什么问题？

公司从事小家电研发、生产和销售，主要采用自主研发、设计、销售及自有品牌运营的经营模式。产品包括豆浆机等食品加工设备、电饭煲等营养煲、西式电器、炊具及净水产品，服务日常制作饮品和烹饪等家庭需求。

### 主要靠什么获得收入？

2025年营业收入82.10亿元。食品加工机占37.80%，营养煲占37.22%，西式电器占18.59%，炊具占4.04%，其他产品及其他业务合计2.35%。按销售渠道划分，线上占66.60%，线下占33.40%；渠道和产品是同一收入的两种分类，不能相加。
