# 立霸股份 · 公司生意笔记

[← 公司目录](README.md) · `603519.SH`

向家电厂商提供用于外观面板的复合材料。

## 生意概览

资料日期：2026-04-18。

### 公司卖什么，解决什么问题？

公司生产家电外观用复合材料，主要是表面涂覆有机涂料的PCM板和表面复合功能薄膜的VCM板，用于冰箱、洗衣机等家电的外观面板。

### 主要靠什么获得收入？

2025年营业收入约16.88亿元，其中有机涂层板（PCM）约15.51亿元，占91.88%；覆膜板（VCM）约0.57亿元，占3.38%；其他约0.80亿元，占4.73%。
