# 西子洁能 · 公司生意笔记

<sub>补充研究笔记 · 原稿 2026-10-13 · 本次整理 2026-10-16。按历史披露阅读，未经旧版网站内容验收。</sub>

看西子洁能的生意，最大的一块是以换热器、压力容器为核心的EP/EPC解决方案，其次才是余热锅炉和清洁能源装备。

资料日期：2026-04-10。

## 公司卖什么，解决什么问题？

西子洁能主要从事余热锅炉、清洁环保能源发电装备的咨询、研发、生产、销售、安装及工程总承包，是我国规模最大、品种最全的余热锅炉研究、开发和制造基地。产品分四类：余热锅炉（燃机、干熄焦、烧结机、水泥窑余热锅炉，电站锅炉及高压加热器等电站辅机）；清洁环保能源装备（垃圾焚烧锅炉、生物质锅炉、废水废气废物锅炉、熔盐吸热器与储罐、核电常规岛辅机及民用核二三级设备）；以导热油换热器、石化化工换热器、海水淡化装置、气化炉等为核心设备的EP/EPC/PC综合解决方案；备件及技术改造、维修维保服务。

## 主要靠什么获得收入？

2025年营业收入62.41亿元，同比下降3.03%。解决方案（EP/EPC等）占46.20%，是最大收入；余热锅炉占22.42%，同比下降37.21%；清洁环保能源装备占18.15%；备件及服务占10.84%。外销占14.39%，同比增长42.46%。

## 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 石化、电力等需要成套能源工程 | 以核心设备加工程总包方式交付EP/EPC项目 | 取得解决方案收入 |
| 工业余热回收与电站需要锅炉装备 | 制造余热锅炉、电站锅炉与辅机 | 取得余热锅炉销售收入 |
| 垃圾焚烧、生物质与核电需要清洁能源装备 | 制造焚烧锅炉、熔盐储热、核电辅机等 | 取得清洁能源装备销售收入 |
| 存量设备需要备件与维保 | 提供备件、技改与维修服务 | 取得备件及服务收入 |

收入主体已从余热锅炉单品转向工程解决方案（占46%）；余热锅炉收入下降37%但解决方案增长19%，口径切换明显，两者毛利率相近（约16-20%）。
