# 京能热力 · 公司生意笔记

京能热力深耕绿色供热和综合能源服务领域，主营业务为热力生产与供应、综合能源及节能技术服务，是北京市采取分布式供热的代表性供热企业，服务居民住宅、商业综合体、办公写字楼、学校等建筑。2025年公司实现营业收入13.33亿元，同比增长24.59%，其中传统能源供热服务占80.94%。

资料日期：2026-04-29。

## 公司卖什么，解决什么问题？

公司提供的是“热”和围绕热的能源服务。主力业务是热力生产与供应：燃烧清洁能源（主要是天然气）或回收低品位工业余热生产热水，通过管网输送，结合智慧能源管控平台精准调节，为居民住宅、商业综合体、办公写字楼、学校等城市各类民用、商用建筑提供冬季供热服务，同时向部分用户提供全年生活热水。其次是综合能源业务：建设多能耦合能源系统，集成地源热泵、空气源热泵、生物质锅炉等多种可再生能源利用技术并结合蓄能，向用户提供供热、供冷、生活热水、蒸汽一体的综合能源服务。此外还有节能技术服务：为客户提供能源系统规划、建设安装、增绿改造、EMC（合同能源管理）、智慧数字运营、碳资产管理等系统性解决方案。

## 主要靠什么获得收入？

2025年营业收入13.33亿元，行业口径全部为热力生产及供应，地区与销售模式口径全部为华北地区直接销售。分产品看：传统能源供热服务10.79亿元（占营业收入80.94%）、系统集成安装及工程收入1.95亿元（占14.60%）、新能源供能服务0.42亿元（占3.12%）、节能技术服务0.05亿元（占0.38%）、其他0.13亿元（占0.95%）。也就是说，烧天然气与回收余热供热的传统供热服务仍是绝对主业，贡献约八成收入；系统集成安装及工程是2025年新列出的第二块收入。

**002893-Q3-C001 · 整理理解**

供热是北方冬季刚需：各类民用、商用建筑用户向公司购买冬季供热（部分购买全年生活热水），公司燃烧天然气或回收工业余热生产热水并经管网输送供热，形成供热服务收入；有多能供应与节能改造需求的客户则带来综合能源与节能技术服务收入。
