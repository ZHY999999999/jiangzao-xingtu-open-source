# 华伍股份 · 公司生意笔记

<sub>补充研究笔记 · 原稿 2026-10-13 · 本次整理 2026-10-16。按历史披露阅读，未经旧版网站内容验收。</sub>

看华伍股份的生意，是给起重机械、风电、矿卡、轨交做制动系统，另有金属管件和航空工装零部件。

资料日期：2026-04-29。

## 公司卖什么，解决什么问题？

华伍股份主要从事工业制动器及其驱动、控制系统的研发、设计、制造、销售和服务，是我国工业制动器现有多项行业标准的第一起草单位。产品覆盖：港口、冶金、水电、海工等起重运输机械的制动系统与防风安全装置（客户含宝武钢铁、鞍钢等）；风力发电机组的主轴制动器、偏航制动器；矿用卡车的液压干盘、湿式多盘制动器；自主研发的摩擦材料衬垫；轨道交通制动系统；另有金属管件、阀门产品和航空工装及零部件业务。

## 主要靠什么获得收入？

2025年营业收入12.86亿元，同比增长6.57%。起重运输制动系统占37.72%，风电制动系统占24.42%，金属管件阀门占18.24%，航空工装及零部件占8.00%（同比下降25.63%），摩擦衬垫占5.12%，轨道交通制动系统占2.38%（同比增长130.28%）。

## 一条生意链

| 谁付钱 | 公司做什么 | 怎样形成收入 |
|---|---|---|
| 起重运输机械需要安全制动 | 制造工业制动器与防风装置 | 取得起重运输制动系统收入 |
| 风电主机厂需要机组制动 | 供应主轴、偏航制动器 | 取得风电制动系统收入 |
| 制动系统需要摩擦材料 | 自研生产摩擦衬垫 | 取得摩擦材料销售收入 |
| 航空制造需要工装与零部件 | 提供航空工装及零部件 | 取得航空业务收入 |

制动主业（起重运输+风电+轨交+摩擦衬垫）约占七成；风电制动毛利率仅1.5%、航空工装毛利率为负，'收入增长6.57%'背后各板块盈亏差异很大。
