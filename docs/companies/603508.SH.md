# 思维列控 · 公司生意笔记

[← 公司目录](README.md) · `603508.SH`

思维列控给铁路客户提供装在列车上及地面的安全设备和系统，帮助控制列车运行、监测设备状态，并发现行车中的风险。

## 生意概览

资料日期：2026-04-11。

### 公司卖什么，解决什么问题？

思维列控的产品围绕列车安全运行展开：列车运行控制系统负责控制列车运行；铁路安全防护系统监测和保护车载设备及作业中的人员、车辆等；高铁运行监测系统采集并分析列车、车载设备和线路环境的信息。公司承担这些系统的研发、生产、集成、销售及技术支持。

### 主要靠什么获得收入？

2025年，列车运行控制系统是最大的收入来源，占全部收入约一半。铁路安全防护系统和高铁运行监测系统各贡献两成多，规模相近。主要收入随铁路客户采购和设备交付形成，设备更新周期与交付节奏会影响当年的收入。
