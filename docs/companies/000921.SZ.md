# 海信家电 · 公司生意笔记

[← 公司目录](README.md) · `000921.SZ`

海信家电有面向家庭和商用场景的家电业务，也有通过三电公司面向车企的空调压缩机与热管理业务。

## 生意概览

资料日期：2026-03-31。

### 公司卖什么，解决什么问题？

公司研发、制造和销售冰箱、家用及中央空调、冷柜、洗衣机、厨房电器等产品，并提供智慧家庭方案。汽车业务通过三电公司向全球车企供应空调压缩机和综合热管理产品，用于车辆制冷、制热及相关热管理需求。

### 主要靠什么获得收入？

2025年营业收入879.28亿元。暖通空调占44.16%，冰洗占35.48%，其他主营占15.14%；这三项合计94.78%，没有覆盖全部营业收入。暖通和冰洗是收入主体，其他主营是合并类别，不能把其中全部金额直接当作汽车热管理收入。
