# 朗鸿科技 · 公司生意笔记

[← 公司目录](README.md) · `920395.BJ`

朗鸿科技做的是零售展示场景里的防盗产品，服务于手机、可穿戴设备等消费电子产品的展示和防盗需求。

## 生意概览

资料日期：2026-04-24。

### 公司卖什么，解决什么问题？

公司研发、生产和销售电子设备防盗展示产品，主要用于智能手机、可穿戴设备等消费电子产品的防盗和展示。国内主要直接面向消费电子行业客户销售，海外则以经销渠道为主。

### 主要靠什么获得收入？

2025年营业收入约1.69亿元，防盗器收入约1.69亿元，按全部营业收入计算约占99.58%；其他收入约占0.42%。公司的收入几乎都来自防盗器产品。
