# ST达华 · 公司生意笔记

[← 公司目录](README.md) · `002512.SZ`

达华的主要收入来自电视机主板。它也为政府和企业开发、集成数字化项目，并经营卫星通信等业务。

## 生意概览

资料日期：2026-04-29。

### 公司卖什么，解决什么问题？

它研发、制造和销售电视主控板、会议及交互显示产品，也提供信息服务平台、系统集成、卫星终端和通信服务。
