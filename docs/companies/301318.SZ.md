# 维海德 · 公司生意笔记

[← 公司目录](README.md) · `301318.SZ`

维海德让远程会议和教学中的画面、声音被采集和传输。摄像机是最大的收入来源，此外还有会议终端、麦克风等音频设备及其他产品。

## 生意概览

资料日期：2026-04-25。

### 公司卖什么，解决什么问题？

它研发、生产和销售高清及超高清视频会议摄像机、会议终端、会议麦克风等设备，并提供相关技术服务，用于商务会议、教育录播、远程医疗和网络直播等场景。客户包括品牌厂商、系统集成商、经销商及其他用户。

### 主要靠什么获得收入？

2025年，摄像机占营业收入70.93%，视频会议终端占6.91%，热成像仪占6.45%，配件及其他占5.38%，网络电话占5.18%，音频设备占5.15%。摄像机仍是最主要的收入来源，其他类别不能与行业分类重复累计。
