# 狄耐克 · 公司生意笔记

[← 公司目录](README.md) · `300884.SZ`

狄耐克围绕居住和医疗场景设计、生产智能产品，帮助建筑内的人与设备连接。楼宇对讲仍是最大收入来源，医院相关产品也是已形成收入的业务。

## 生意概览

资料日期：2026-04-28。

### 公司卖什么，解决什么问题？

它研发、制造和销售楼宇对讲、智能家居、智慧病房和智慧门诊等产品，并延伸到智能门锁、全空气系统等场景。主要服务智慧社区与智慧医院的建设和使用需求。

### 主要靠什么获得收入？
