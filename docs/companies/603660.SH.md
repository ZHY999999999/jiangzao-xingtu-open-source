# 苏州科达 · 公司生意笔记

[← 公司目录](README.md) · `603660.SH`

苏州科达把摄像、存储、分析和通信设备与软件组合起来，帮助政府和企业开远程会议、看现场情况，并把音视频信息用到日常管理中。

## 生意概览

资料日期：2026-04-29。

### 公司卖什么，解决什么问题？

苏州科达主要做三类生意：视频会议产品用于远程开会、会商和指挥调度；视频监控产品负责采集、存储和分析现场画面；行业应用产品与解决方案把这些音视频能力接入公安、交通、应急等具体业务。公司交付的是设备、软件及应用方案。

### 主要靠什么获得收入？

2025年，视频会议是最大的产品收入来源，行业应用产品与解决方案紧随其后，视频监控排在第三。三类主营业务合起来贡献了绝大多数收入。人工智能是多种产品中使用的技术，年报没有把它单独列成第四条产品收入。
