# 儒竞科技 · 公司生意笔记

[← 公司目录](README.md) · `301525.SZ`

儒竞科技的产品用于控制电机和电力转换，主要客户是设备及汽车零部件厂商。

## 生意概览

资料日期：2026-04-28。

### 公司卖什么，解决什么问题？

公司研发、生产和销售变频驱动器、系统控制器、伺服驱动器和伺服电机。这些部件用于空调、热泵、冷冻冷藏设备，新能源汽车热管理，以及自动化设备的运动控制。

### 主要靠什么获得收入？

2025年营业收入约12.86亿元，其中暖通空调及冷冻冷藏设备领域约7.82亿元，占60.85%；新能源汽车热管理系统约4.63亿元，占36.05%；伺服驱动及控制系统占2.78%，其他业务占0.32%。
